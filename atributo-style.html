HTML O Atributo style

Na aula Ligar CSS, o CSS ficou num arquivo separado ou num <style> no head. Existe um terceiro lugar: dentro da própria tag, no atributo style. É o jeito mais rápido de mudar a cor de uma palavra, e é por isso que ele aparece em tanto código copiado da internet. Também é o jeito mais fácil de bagunçar um site. Nesta aula você vai aprender a escrever o style, entender por que ele vence as outras regras e saber quando ele vale a pena.

Você vai aprender
  • Como escrever o atributo style: style="propriedade: valor;".
  • Como pôr vários ajustes no mesmo style.
  • Por que o style vence o CSS do head (e a exceção !important).
  • O cuidado com as aspas dentro das aspas.
  • Quando usar e quando evitar.
  • Os erros reais do validador W3C, que confere o CSS de dentro do style.

Os arquivos desta aula foram validados com o validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/attr. O que o navegador aplicou (as cores, o negrito) foi conferido no Chrome.

A ideia: o bilhete colado no produto

Na lojinha da Ana, as regras do uniforme estão no manual da parede (o arquivo .css). Mas, num dia de promoção, ela cola um bilhete direto num caderno: "este aqui com etiqueta vermelha". O bilhete vale só para aquele caderno, e ganha do manual: se o manual diz "etiqueta azul", o caderno do bilhete fica com a vermelha.

O atributo style é esse bilhete: CSS colado num elemento só.

1. A forma do style

O style é um atributo como outro qualquer (aula Atributos): vai na tag de abertura, com o valor entre aspas. O valor é CSS, sem seletor e sem chaves, porque o elemento já é a própria tag:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <p style="color: crimson;">Promoção: bolo de cenoura pela metade do preço!</p>
  <p>Pão de queijo, brigadeiro e torta de limão.</p>
</body>
</html>
<p
A tag de abertura do elemento que vai mudar.
style=
O atributo. Style = "estilo".
"
As aspas abrem o valor. Sempre use aspas no style (a seção 4 mostra por quê).
color
A propriedade de CSS: a cor do texto.
: crimson
Dois-pontos e o valor. crimson é um vermelho-escuro, um dos nomes de cor do CSS.
;
Termina o ajuste.
">
Fecha as aspas e a tag.

Só o primeiro parágrafo ficou vermelho: o style vale para aquele elemento (e para o que estiver dentro dele), e para mais nenhum. Compare com a regra de CSS da aula anterior:

No <style> ou no .cssNo atributo style
p { color: crimson; }<p style="color: crimson;">
Tem seletor (p) e chaves: vale para todos os pSem seletor nem chaves: vale para este p

Vários ajustes

Para mudar mais de uma coisa, separe os ajustes com ;, tudo dentro das mesmas aspas:

<p style="color: crimson; font-weight: bold; text-align: center;">Promoção: bolo de cenoura pela metade do preço!</p>
color: crimson;
Cor vermelho-escura.
font-weight: bold;
Font weight = "peso da fonte"; bold = negrito.
text-align: center;
Text align = "alinhamento do texto"; center = centralizado.

O ; do último ajuste é opcional, mas deixe-o: quando você acrescentar outro ajuste depois, ele já está lá.

$ vnu --verbose certo.html
certo.html

2. O style vence o CSS do head

Agora a página tem uma regra no head dizendo que todo parágrafo é verde, e o primeiro parágrafo tem um style dizendo vermelho:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
  <style>
    p { color: green; }
  </style>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <p style="color: crimson;">Promoção: bolo de cenoura pela metade do preço!</p>
  <p>Pão de queijo, brigadeiro e torta de limão.</p>
</body>
</html>

O primeiro parágrafo ficou vermelho (o Chrome informou rgb(220, 20, 60), o crimson), e o segundo, verde. Na aula anterior, entre o link e o style, vencia quem vinha por último. Com o atributo style é diferente: ele vence o CSS do head e dos arquivos .css sempre, venha antes ou depois. É como o bilhete colado no produto: ele é mais específico que o manual da parede.

A exceção: !important

No CSS existe um jeito de "gritar" mais alto que o style: pôr !important ("importante") depois do valor.

<style>
  p { color: green !important; }
</style>

Com isso no head, o parágrafo do style="color: crimson;" ficou verde no Chrome (rgb(0, 128, 0)), e o negrito, que não estava na briga, continuou. Você vai encontrar !important em código de outras pessoas, quase sempre como remendo de uma briga entre regras. Evite: depois de um, vem outro para vencer o primeiro, e ninguém mais sabe quem manda. (A ordem completa de quem vence quem é a "cascata", assunto do futuro Guia CSS.)

3. Quando usar e quando evitar

Agora imagine a página de receitas com dez parágrafos de promoção, cada um com o seu bilhete:

<p style="color: crimson; font-weight: bold;">Bolo de cenoura pela metade do preço!</p>
<p style="color: crimson; font-weight: bold;">Brigadeiro: leve 10, pague 8!</p>
<p style="color: crimson; font-weight: bold;">Torta de limão com 20% de desconto!</p>

No dia em que a Ana decidir que as promoções são laranja, ela tem de achar e trocar cada style, em cada página, e vai esquecer algum. Com uma regra no .css e uma classe nos parágrafos, seria uma linha só. As classes são a próxima aula: class e id.

Use o style quando…Evite o style quando…
É um teste rápido, para ver como ficaO mesmo ajuste se repete em vários elementos
É um ajuste único, que só aquele elemento temÉ a aparência geral do site (cores, fontes, espaços)
O valor é calculado por um programa em JavaScript (por exemplo, a largura de uma barra de progresso)O site tem uma política de segurança que bloqueia estilos na tag (aula Segurança)
Você escreve um e-mail em HTML (muitos programas de e-mail só entendem o style)Você quer que o HTML fique fácil de ler: tags cheias de style escondem o conteúdo
O style não muda o significado

Um <p style="font-size: 2em; font-weight: bold;"> fica com cara de título, mas continua sendo um parágrafo: o leitor de tela e o Google não o tratam como título. Para um título, use <h2> (aula Títulos), e mude a aparência dele com CSS. O mesmo vale para negrito: font-weight: bold só engrossa a letra; <strong> diz que o texto é importante (aula Negrito e Itálico).

4. As aspas

O HTML aceita valores de atributo sem aspas, desde que não tenham espaço. Por isso <p style=color:crimson> passa no validador e funciona. Mas basta um espaço:

<p style=color: crimson>Promoção</p>

Sem aspas, o valor termina no primeiro espaço. O navegador leu style="color:" (um ajuste sem valor) e um segundo atributo chamado crimson. No Chrome, os atributos do parágrafo ficaram style e crimson, e o texto saiu preto. O validador:

$ vnu sem-aspas-espaco.html
"file:/home/ana/attr/sem-aspas-espaco.html":9.3-9.26: error: Attribute “crimson” not allowed on element “p” at this point.
"file:/home/ana/attr/sem-aspas-espaco.html":9.3-9.26: error: CSS: “color”: Parse Error.

"O atributo crimson não é permitido no p" e "erro de leitura do CSS em color". Regra do guia: sempre aspas duplas no style.

Missão: o parágrafo deveria estar vermelho-escuro, mas está preto. Conserte o atributo style.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <p style=color: crimson>Promoção: brigadeiro, leve 10 e pague 8!</p>
</body>
</html>

Aspas dentro das aspas

Alguns valores de CSS levam aspas, como o nome de uma fonte com espaço ("Courier New"). Dentro de um style="…", aspas duplas fecham o atributo:

<p style="font-family: "Courier New", monospace">Promoção</p>

Para o navegador, o style terminou em font-family: , e o resto virou atributos com nomes esquisitos. No Chrome, o parágrafo ficou com três atributos: style, courier e new",… (e mais um, monospace"). O validador mostra a confusão inteira:

$ vnu aspas.html
"file:/home/ana/attr/aspas.html":9.3-9.27: error: No space between attributes.
"file:/home/ana/attr/aspas.html":9.3-9.38: error: Quote “"” in attribute name. Probable cause: Matching quote missing somewhere earlier.
"file:/home/ana/attr/aspas.html":9.3-9.50: error: Quote “"” in attribute name. Probable cause: Matching quote missing somewhere earlier.
"file:/home/ana/attr/aspas.html":9.3-9.51: error: Attribute “courier” not allowed on element “p” at this point.
"file:/home/ana/attr/aspas.html":9.3-9.51: error: Attribute “new",” not allowed on element “p” at this point.
"file:/home/ana/attr/aspas.html":9.3-9.51: error: Attribute “monospace"” not allowed on element “p” at this point.
"file:/home/ana/attr/aspas.html":9.3-9.51: error: CSS: “font-family”: Parse Error.
  • No space between attributes: "falta espaço entre os atributos": logo depois das aspas que fecharam o style veio Courier, grudado.
  • Quote “"” in attribute name. Probable cause: Matching quote missing somewhere earlier.: "aspas no nome de um atributo; causa provável: faltou fechar aspas em algum lugar antes". É a pista certa.
  • Os Attribute “…” not allowed são os pedaços que viraram atributos.

O conserto: dentro de aspas duplas, use aspas simples (ou o contrário):

<p style="font-family: 'Courier New', monospace;">Promoção: cadernos com 30% de desconto!</p>

Válido, e o Chrome aplicou a fonte "Courier New", monospace (o monospace é o plano B: qualquer fonte de largura fixa, se a Courier New não estiver instalada).

Quando dá errado

O validador W3C confere o CSS de dentro do style, como confere o do <style>. As mensagens começam com CSS: e o nome da propriedade. O navegador, por sua vez, não mostra erro nenhum: ele simplesmente ignora o ajuste que não entendeu.

error: CSS: “color”: “vermelho” is not a “color” value.

O que significa: "vermelho não é um valor de cor". Os nomes de cor do CSS são em inglês: red, crimson, green, darkorange… No Chrome, o texto ficou preto.

Como consertar: use um nome em inglês, ou um código de cor como #dc143c (assunto do futuro Guia CSS).

error: CSS: “colour”: Property “colour” doesn't exist.

O que significa: "a propriedade colour não existe". É a grafia britânica; o CSS usa a americana, color. O mesmo erro aparece para cor, colr, font-wieght…

Como consertar: corrija o nome da propriedade.

error: CSS: “color”: Missing a semicolon before the property name “font-weight”.

O que significa: style="color: crimson font-weight: bold", sem o ; entre os ajustes. O navegador lê os dois como um só, sem sentido, e joga os dois fora: no Chrome, o texto ficou preto e sem negrito.

Como consertar: style="color: crimson; font-weight: bold;".

error: CSS: “color”: Parse Error.

O que significa: "erro de leitura": o CSS está mal formado. Em style="color crimson", faltaram os dois-pontos. Com style="p { color: crimson; }" (uma regra inteira, com seletor e chaves), aparece CSS: “p”: Parse Error.: no atributo style não vai seletor.

Como consertar: só propriedade: valor;, sem seletor e sem chaves.

Nenhum erro no validador, mas o estilo não funciona: style="{color: crimson}"

O que significa: as chaves em volta. O validador não reclamou, mas o Chrome ignorou tudo e o texto ficou preto.

Como consertar: tire as chaves: style="color: crimson;".

error: CSS: “font-size”: only “0” can be a “unit”. You must put a unit after your number.

O que significa: font-size: 20, sem unidade. "Só o zero pode ficar sem unidade; ponha uma unidade depois do número." 20 o quê? Pixels, em…? O Chrome ignorou o ajuste (a letra ficou com os 16 pixels normais), mas aplicou os outros do mesmo style.

Como consertar: font-size: 20px; (px = pixels).

error: Duplicate attribute “style”.

O que significa: dois atributos style na mesma tag: <p style="color: crimson;" style="font-weight: bold;">. O navegador fica com o primeiro e joga o segundo fora: no Chrome, o texto ficou vermelho, mas sem negrito.

Como consertar: junte tudo num style só: style="color: crimson; font-weight: bold;".

Resumo

  • O atributo style põe CSS direto num elemento: <p style="color: crimson; font-weight: bold;">. Sem seletor e sem chaves; ajustes separados por ;.
  • Ele vale só para aquele elemento e vence o CSS do head e dos arquivos .css (exceto o !important, que é melhor evitar).
  • Sempre aspas duplas no style; aspas dentro dele, simples.
  • Use para ajustes únicos e testes. Para o que se repete, use uma classe e um arquivo .css (próxima aula, class e id).
  • O navegador ignora em silêncio o que não entende (vermelho, colour, ; faltando, número sem unidade); o validador acusa, com mensagens que começam com CSS:.
