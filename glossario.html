HTML Glossário

Os termos que aparecem no guia, em ordem alfabética, explicados em uma ou duas frases, cada um com o link para a aula em que ele é explicado com calma. Os termos em inglês vêm com a tradução. Quando o nome em inglês é o mais usado no dia a dia (como tag ou link), ele é o título do verbete.

Dica

Use Ctrl+F no navegador para achar um termo, ou o índice de letras abaixo. Para consultas rápidas, veja também as referências de Todos os Elementos, Atributos, Tipos de input, Entidades, Metas do head e Mensagens do Validador.

A · B · C · D · E · F · G · H · I · J · L · M · N · O · P · Q · R · S · T · U · V · W

A

Acessibilidade
Fazer a página funcionar para todo mundo: quem não enxerga e usa leitor de tela, quem só usa o teclado, quem enxerga pouco e dá zoom. Começa com HTML bem escrito: alt nas imagens, label nos campos, títulos em ordem e o lang da página. Veja: Acessibilidade.
action
O atributo do <form> que diz para onde os dados vão quando o formulário é enviado. Veja: Enviar (action, method, GET e POST).
alt (texto alternativo)
O atributo do <img> com a descrição da imagem, lida pelo leitor de tela e mostrada quando a imagem não carrega. É obrigatório; numa imagem só de enfeite, fica vazio: alt="". Veja: Texto Alternativo (alt).
Âncora
Um link para um ponto da mesma página: <a href="#contato"> leva ao elemento com id="contato". O nome do elemento <a> vem de anchor, âncora. Veja: Âncoras na Mesma Página.
Aninhamento
Colocar um elemento dentro de outro: <p>Bolo de <strong>cenoura</strong></p>. O que abre por último fecha primeiro, como caixas umas dentro das outras. Veja: Aninhamento.
ARIA
"Accessible Rich Internet Applications": atributos role e aria-* que dão informações extras aos leitores de tela. A primeira regra do ARIA é: se existe um elemento HTML que faz o serviço (um <button>), use o elemento. Veja: ARIA.
async e defer
Atributos do <script src> que fazem o navegador baixar o JavaScript sem parar de ler o HTML. Com defer, ele roda no fim, na ordem; com async, assim que chega. Veja: Desempenho (preload e defer).
Atributo
Uma informação extra na tag de abertura, no formato nome="valor": em <a href="sobre.html">, o atributo é href. Veja: Atributos e a referência Atributos.
Atributo booleano
Um atributo que funciona como interruptor: estar escrito já liga (required, disabled, checked). Escrever ="false" não desliga; para desligar, apague o atributo. Veja: Atributos booleanos.
Atributos globais
Os atributos que valem em qualquer elemento: id, class, style, title, lang, hidden, tabindex, data-*… Veja: Atributos Globais.
AVIF
Um formato de imagem moderno que costuma dar arquivos bem menores que o JPG com a mesma qualidade. Veja: Formatos (JPG, PNG, WebP, SVG, AVIF).
Aviso (warning)
Uma mensagem do validador que não é erro: o HTML vale, mas há algo a melhorar. No vnu, aparece como info warning. Veja: Mensagens do Validador.

B

Baseline
Um selo que diz se um recurso da web já funciona em todos os navegadores principais (Chrome, Edge, Firefox e Safari). Ajuda a decidir se uma novidade já pode ser usada. Veja: Novidades do HTML.
Bloco (elemento de bloco)
Um elemento que começa numa linha nova e ocupa a largura toda, como <p>, <h1>, <div> e <ul>. O contrário é "em linha". Veja: Bloco × Em Linha.
body
O "corpo" da página: tudo o que aparece na tela fica dentro de <body>. Veja: Estrutura de uma Página.

C

Caminho absoluto
Um endereço completo, com o site: https://exemplo.com/receitas/bolo.html. Use para links para outros sites. Veja: Caminhos Relativos e Absolutos.
Caminho relativo
Um endereço que parte da página atual: bolo.html (mesma pasta), img/bolo.jpg (uma pasta abaixo), ../index.html (uma pasta acima). É o jeito certo de ligar as páginas do seu próprio site. Veja: Caminhos Relativos e Absolutos.
charset
"Character set", a codificação dos caracteres do arquivo. Toda página do guia começa o head com <meta charset="utf-8">. Veja: Acentos, UTF-8 e Emoji.
class
Atributo que dá um ou mais nomes a um elemento, para o CSS e o JavaScript acharem grupos de elementos: class="receita destaque". Vários elementos podem ter a mesma classe. Veja: class e id.
Código-fonte
O texto HTML de uma página, como foi escrito. Na maioria dos navegadores de computador, Ctrl+U mostra o código-fonte da página aberta. Veja: Ferramentas do Desenvolvedor (F12).
Comentário
Um texto entre <!-- e -->, que o navegador não mostra. Serve para anotações. Atenção: quem abre o código-fonte vê. Veja: Comentários.
Componente (Web Component)
Um elemento que você mesmo cria, com nome próprio (como <cartao-receita>) e comportamento em JavaScript. Veja: Web Components.
CSP
"Content Security Policy", política de segurança de conteúdo: uma regra que diz de onde a página pode carregar scripts, estilos e imagens. Atrapalha quem tenta injetar código na sua página. Veja: Segurança (rel, sandbox, CSP).
CSS
"Cascading Style Sheets", folhas de estilo em cascata: a linguagem que cuida da aparência (cores, fontes, espaços, posição). O HTML diz o que cada coisa é; o CSS, como ela fica. Veja: Ligar CSS (link e style).

D

data-*
Atributos com nome livre depois de data-, para guardar dados seus num elemento: data-preco="12.90". O JavaScript lê pelo dataset. Veja: Atributos data-*.
Dados estruturados
Informações escritas num formato que os buscadores entendem (o mais comum é o JSON-LD), como o tempo de preparo e a nota de uma receita. Podem aparecer como resultados "enriquecidos" na busca. Veja: Dados Estruturados (JSON-LD).
DevTools (F12)
As Ferramentas do Desenvolvedor do navegador: mostram o DOM, o CSS, o console e os arquivos carregados. Abrem com F12 na maioria dos navegadores de computador. Veja: Ferramentas do Desenvolvedor (F12).
DOCTYPE
A primeira linha da página, <!DOCTYPE html>. Não é uma tag: é um aviso para o navegador desenhar a página no modo padrão de hoje, e não no modo quirks. Veja: O DOCTYPE.
DOM
"Document Object Model", modelo de objetos do documento: a árvore de elementos que o navegador monta depois de ler o HTML, já com os erros consertados. É o que o DevTools mostra e o que o JavaScript altera. Veja: Como o Navegador Lê HTML.

E

Editor de código
Um programa para escrever código, com cores, sugestões e atalhos, como o VS Code. O HTML também pode ser escrito num editor de texto simples, mas nunca num processador de texto como o Word. Veja: Editores (VS Code e outros).
Elemento
Uma peça da página: tag de abertura, conteúdo e tag de fechamento, como <p>Olá</p>. Veja: Elementos e Tags e a lista em Todos os Elementos.
Elemento vazio
Um elemento sem conteúdo e sem tag de fechamento. São 13: area, base, br, col, embed, hr, img, input, link, meta, source, track e wbr. Veja: Os elementos vazios.
Em linha (inline)
Um elemento que fica no meio do texto, sem quebrar a linha, como <a>, <strong> e <span>. Veja: Bloco × Em Linha.
Entidade (referência de caractere)
Um código entre & e ; que vira um caractere: &lt; vira <, &amp; vira &, &nbsp; vira um espaço que não quebra. Veja: Entidades e a tabela em Entidades.
Escapar
Trocar um caractere especial pela entidade dele, para que ele apareça como texto em vez de virar código: escrever &lt;p&gt; para mostrar <p>. Veja: Entidades e Código (code, pre, kbd).

F

Favicon
O ícone pequeno que aparece na aba do navegador e nos favoritos, ligado com <link rel="icon">. Veja: Ícone da Aba (favicon).
Filho, pai e descendente
Os parentescos da árvore do HTML: em <ul><li>…</li></ul>, o li é filho do ul, e o ul é pai do li. Descendente é quem está dentro, em qualquer nível. Veja: Aninhamento.
Foco
O elemento que recebe o que você digita agora. A tecla Tab passa o foco de um link, botão ou campo para o próximo; o navegador costuma desenhar um contorno no elemento com foco. Veja: Teclado e Foco (tabindex).
Formulário
Um conjunto de campos (input, select, textarea…) dentro de <form>, que o leitor preenche e envia. Veja: Formulários.

G

GET e POST
Os dois jeitos de enviar um formulário (method). No GET, os dados vão no endereço, depois do ? (bom para buscas); no POST, vão no corpo do pedido (bom para cadastros, senhas e arquivos). Veja: Enviar (action, method, GET e POST).
GitHub Pages
Um serviço gratuito do GitHub que publica um site estático (HTML, CSS, imagens) a partir de um repositório. Veja: Publicar no GitHub Pages.

H

head
A "cabeça" da página: título, codificação, CSS, ícone e metas. O que está no <head> não aparece na tela. Veja: O head.
Hipertexto
Texto com links que levam a outros textos. É o "HT" de HTML e de HTTP. Veja: O que é HTML.
href
"Hypertext reference": o atributo com o endereço de destino de um link (<a>) ou de um arquivo ligado (<link>). Veja: Links.
HTML
"HyperText Markup Language", linguagem de marcação de hipertexto: a linguagem que diz o que cada parte de uma página é (título, parágrafo, link, imagem). Não é uma linguagem de programação. Veja: O que é HTML.
HTML Living Standard (HTML5)
A versão do HTML de hoje, mantida pelo WHATWG e atualizada aos poucos, sem números de versão. É o que muita gente ainda chama de "HTML5". Veja: Versões do HTML.
HTTP e HTTPS
As regras de conversa entre o navegador e o servidor: o navegador pede um arquivo, o servidor responde. O HTTPS é a versão com criptografia (o cadeado na barra de endereço). Veja: Como o Navegador Lê HTML e Servidor Local.

I

id
Atributo que dá um nome único a um elemento na página. É usado por âncoras (#id), pelo label for, pelo CSS e pelo JavaScript. Veja: class e id.
iframe
"Inline frame": um quadro que mostra outra página dentro da sua, como um mapa ou um vídeo de outro site. Veja: iframe.
index.html
O nome da página inicial de uma pasta. Quando alguém abre o endereço de uma pasta do site, o servidor entrega o index.html dela. Veja: Organizar os Arquivos de um Site.
input
O campo de formulário, um elemento vazio cujo atributo type muda tudo: texto, e-mail, data, caixa de marcar, cor… Veja: O Elemento input e Tipos de input.

J

JavaScript
A linguagem de programação dos navegadores: faz a página reagir a cliques, conferir formulários e mudar o conteúdo. Entra no HTML pelo elemento <script>. Veja: O Elemento script.
JSON-LD
O formato mais usado para dados estruturados: um bloco <script type="application/ld+json"> com as informações da página para os buscadores. Veja: Dados Estruturados (JSON-LD).

L

label
O rótulo de um campo de formulário. Ligado ao campo (pelo for ou envolvendo-o), faz o leitor de tela dizer o nome do campo, e um clique no rótulo põe o cursor no campo. Veja: label.
lang
Atributo que diz o idioma do conteúdo. No <html lang="pt-BR">, vale para a página inteira e ajuda o leitor de tela a pronunciar certo. Veja: Estrutura de uma Página.
Lazy loading (carregamento preguiçoso)
Deixar uma imagem ou um iframe para ser baixado só quando ele chega perto da tela: loading="lazy". Veja: Carregamento Preguiçoso (loading).
Leitor de tela
Um programa que lê a tela em voz alta (ou em braile) para quem não enxerga, como o NVDA, o VoiceOver e o TalkBack. Ele se guia pelo HTML: títulos, links, alt, rótulos. Veja: Leitores de Tela.
Link (hiperligação)
Um texto ou imagem que leva a outro endereço quando clicado: <a href="sobre.html">Sobre</a>. Não confunda com o elemento <link> do head, que liga arquivos (como o CSS) à página. Veja: Links.
localhost
"O próprio computador": o endereço que você usa para ver um site servido por um servidor local, como http://localhost:8000/. Veja: Servidor Local.

M

Marcação (markup)
Marcar um texto com etiquetas que dizem o que cada pedaço é, como um professor que circula o título e sublinha as palavras importantes. É o "M" de HTML. Veja: O que é HTML.
meta
Elemento vazio do head com informações sobre a página: codificação, viewport, descrição, imagem de compartilhamento. Veja: title e meta e Metas do head.
Metadados
Dados sobre os dados: as informações sobre a página (título, idioma, autor, codificação), que ficam no head. Veja: O head.
method
O atributo do <form> que escolhe como os dados vão: get (o padrão) ou post. Veja: Enviar (action, method, GET e POST).
Modo quirks
O "modo de manias": como o navegador desenha uma página sem <!DOCTYPE html>, imitando os erros de navegadores muito antigos. O contrário é o modo padrão. Veja: O DOCTYPE.

N

name
Num campo de formulário, o nome com que o valor é enviado: name="email" envia email=…. Campo sem name não é enviado. Veja: Formulários.
Navegador (browser)
O programa que pede as páginas, lê o HTML, monta o DOM e desenha o resultado: Chrome, Edge, Firefox, Safari. Veja: Como o Navegador Lê HTML.

O

Obsoleto
Um elemento ou atributo que saiu do HTML, como <center>, <font> e bgcolor. O navegador ainda costuma obedecer, mas o validador acusa. Veja: Versões do HTML e Elementos obsoletos.
Open Graph
As metas og:title, og:description, og:image… que as redes sociais e os aplicativos de mensagem leem para montar o cartão de um link compartilhado. Veja: Open Graph (Redes Sociais).

P

Parser (analisador)
A parte do navegador que lê o texto HTML, letra por letra, e monta a árvore do DOM. É ele que conserta sozinho as tags mal fechadas. Veja: Como o Navegador Lê HTML.
Pasta raiz
A pasta principal do site, onde fica o index.html e de onde partem as outras pastas (img/, css/). Veja: Organizar os Arquivos de um Site.
placeholder
O texto de exemplo, em cinza, que aparece dentro de um campo vazio e some quando você digita. Não substitui o label. Veja: placeholder, value, autocomplete….
popover
Atributo que transforma um elemento numa caixa que aparece por cima da página, aberta e fechada por um botão com popovertarget, sem JavaScript. Veja: popover.
Porta
O número que vem depois dos dois-pontos num endereço, como o 8000 de localhost:8000. Diz com qual programa do computador o navegador está falando. Veja: Servidor Local.

Q

Quebra de linha
No código, apertar Enter não quebra a linha na tela: o navegador junta os espaços e as quebras. Para quebrar dentro de um texto, use <br>; para um assunto novo, um novo <p>. Veja: Espaços e Quebras de Linha e Quebras (br e hr).

R

rel
Atributo que diz a relação entre a página e o destino de um link ou arquivo: rel="stylesheet" (é o CSS), rel="icon" (é o ícone), rel="noopener" (abra sem dar acesso a esta página). Veja: Nova Aba (target e rel).
Responsivo
Um site que se ajusta a qualquer tela, do celular ao monitor grande. No HTML, começa com a meta viewport e com imagens em vários tamanhos (srcset). Veja: Celular (meta viewport) e Imagens Responsivas (srcset).
robots.txt
Um arquivo de texto na raiz do site com pedidos para os robôs dos buscadores (o que podem visitar). É um pedido, não uma tranca. Veja: robots.txt e sitemap.

S

sandbox
"Caixa de areia": o atributo do <iframe> que prende a página de dentro, sem scripts, formulários nem janelas, a não ser o que você liberar. Veja: Segurança (rel, sandbox, CSP).
Semântica (HTML semântico)
Escolher o elemento pelo significado, e não pela aparência: <nav> para o menu, <button> para um botão, <h2> para um subtítulo. Ajuda os leitores de tela e os buscadores. Veja: HTML Semântico.
SEO
"Search Engine Optimization", otimização para buscadores: cuidar para que a página seja bem entendida e bem mostrada no Google e companhia (título, descrição, títulos em ordem, texto alternativo). Veja: HTML e SEO.
Servidor
O programa (e o computador) que entrega os arquivos do site quando o navegador pede. Para testar, você pode rodar um no próprio computador: python3 -m http.server. Veja: Servidor Local.
Site estático
Um site feito só de arquivos prontos (HTML, CSS, imagens, JavaScript), entregues como estão, sem programa no servidor montando as páginas. É o que o GitHub Pages publica, e o que este guia é. Veja: Publicar no GitHub Pages.
sitemap
Um arquivo (sitemap.xml) com a lista das páginas do site, para os buscadores acharem todas. Veja: robots.txt e sitemap.
src
"Source", fonte: o atributo com o endereço do arquivo de uma imagem, vídeo, áudio, script ou iframe. Veja: Imagens.
srcset
Atributo do <img> com várias versões da imagem em tamanhos diferentes; o navegador escolhe a melhor para a tela. Veja: Imagens Responsivas (srcset).
SVG
"Scalable Vector Graphics": um formato de imagem feito de formas descritas em texto, que fica nítido em qualquer tamanho. Pode ser um arquivo ou ir direto no HTML. Veja: SVG no HTML.

T

tabindex
Atributo que põe um elemento na ordem da tecla Tab (0) ou só permite o foco por JavaScript (-1). Valores maiores que 0 bagunçam a ordem e devem ser evitados. Veja: Teclado e Foco (tabindex).
Tag
A etiqueta entre < e > que abre (<p>) ou fecha (</p>) um elemento. Tag é o pedaço de código; elemento é a peça inteira. Veja: Elementos e Tags.
target
Atributo de link que diz onde abrir o destino: _blank abre numa nova aba. Veja: Nova Aba (target e rel).
template
Elemento que guarda um pedaço de HTML sem mostrá-lo, para o JavaScript copiar e usar várias vezes. Veja: template e slot.
title
Dois usos: o elemento <title>, no head, é o título da aba e da busca (obrigatório); o atributo title é a dica que aparece quando o mouse para sobre um elemento. Veja: title e meta e Atributos.

U

Unicode
A grande tabela que dá um número a cada caractere de todas as escritas do mundo, e aos emojis: o © é o U+00A9, o 🎂 é o U+1F382. As entidades numéricas usam esses números. Veja: Acentos, UTF-8 e Emoji.
URL
"Uniform Resource Locator": o endereço de um arquivo na web, como https://exemplo.com/receitas/bolo.html. Veja: Caminhos Relativos e Absolutos.
UTF-8
O jeito de gravar os caracteres do Unicode num arquivo usado por quase toda a web. Com <meta charset="utf-8"> e o arquivo salvo em UTF-8, acentos e emojis aparecem certos. Veja: Acentos, UTF-8 e Emoji.

V

Validador
O programa que confere se o HTML segue as regras do padrão e diz onde estão os erros. O oficial é o do W3C: on-line, em validator.w3.org/nu, ou no terminal, com o vnu. Veja: Validar o HTML e Mensagens do Validador.
value
O valor de um campo: o texto inicial de um input, ou o que é enviado por uma opção, uma caixa de marcar ou um botão. Veja: placeholder, value, autocomplete….
viewport
A área da tela onde a página é desenhada. A meta <meta name="viewport" content="width=device-width, initial-scale=1"> faz a página caber na largura do celular. Veja: Celular (meta viewport).
vnu
O "Nu Html Checker", o validador do W3C em forma de programa de terminal. É o mesmo que roda no validator.w3.org. Veja: Validar o HTML.
VS Code
O Visual Studio Code, um editor de código gratuito, o mais usado hoje. Veja: Editores (VS Code e outros).

W

W3C
"World Wide Web Consortium": o consórcio que cuida de padrões da web (como o CSS) e mantém o validador oficial. Veja: Versões do HTML.
WCAG
"Web Content Accessibility Guidelines": as diretrizes de acessibilidade do W3C, a lista de critérios usada para dizer se um site é acessível. Veja: Acessibilidade.
WebP
Um formato de imagem moderno, aceito por todos os navegadores atuais, que costuma dar arquivos menores que o JPG e o PNG. Veja: Formatos (JPG, PNG, WebP, SVG, AVIF).
WebVTT
O formato de arquivo de legendas (.vtt) usado pelo elemento <track> nos vídeos. Veja: Legendas (track e WebVTT).
WHATWG
"Web Hypertext Application Technology Working Group": o grupo, formado pelas empresas dos navegadores, que escreve o HTML Living Standard. Veja: Versões do HTML.
