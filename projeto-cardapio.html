Projeto Cardápio

A Ana abriu um café pequeno na frente da casa dela e quer o cardápio no site: o nome de cada item, uma descrição curta e o preço. Isso é uma tabela: linhas (os itens) e colunas (item, descrição, preço). Neste projeto você monta uma tabela completa, com cabeçalho, grupos, legenda e rodapé, do jeito que um leitor de tela consegue ler para quem não enxerga a tela.

Você vai praticar
  • Montar uma tabela com table, tr e td (Tabelas).
  • Separar o cabeçalho com th, thead e tbody (Cabeçalhos).
  • Dar um nome à tabela com caption e dizer a quem cada cabeçalho se refere com scope (Legenda e Acessibilidade).
  • Juntar células com colspan (Mesclar Células).
  • Fechar a tabela com um rodapé, o tfoot.
  • Ver como o navegador conserta uma tabela errada e o que o validador diz.

O que vamos construir

O cardápio pronto, desenhado pelo seu navegador:

<!DOCTYPE html>

  2. O cabeçalho e a legenda (th, thead, tbody, caption).
  3. Os grupos: salgados, doces e bebidas (vários tbody, colspan e scope).
  4. O rodapé (tfoot).

Antes de começar

Você precisa ter visto Tabelas e Cabeçalhos; para a versão 3, Mesclar Células e Legenda e Acessibilidade. A pasta do projeto:

$ mkdir -p sites/cardapio
$ cd sites/cardapio

Versão 1 · A tabela mais simples

Pense numa planilha: cada linha é um item do cardápio e cada célula da linha é uma informação dele. No HTML, você escreve a tabela linha por linha, da esquerda para a direita. As colunas não são escritas em lugar nenhum: elas aparecem sozinhas, porque toda linha tem três células.

  <meta name="viewport" content="width=device-width, initial-scale=1">

    th, td { border: 1px solid #999; padding: 6px 10px; text-align: left; }
  </style>
</head>
<body>
  <h1>Café da Ana</h1>
  <p>Tudo feito na hora, com receitas da família.</p>
  <table>
    <tr>
      <td>Item</td>
      <td>Descrição</td>
      <td>Preço</td>
    </tr>
    <tr>
      <td>Pão de queijo</td>
      <td>Porção com 6 unidades</td>
      <td>R$ 9,00</td>
    </tr>
    <tr>
      <td>Bolo de cenoura</td>
      <td>Fatia com cobertura de chocolate</td>
      <td>R$ 8,00</td>
    </tr>
    <tr>
      <td>Café coado</td>
      <td>Xícara de 150 ml</td>
      <td>R$ 5,00</td>
    </tr>
    <tr>
      <td>Brigadeiro</td>
      <td>Unidade</td>
      <td>R$ 3,50</td>
    </tr>
  </table>
</body>

<table>
A tabela inteira.
<tr>
Table row, "linha da tabela". Uma por item (e uma para os títulos, por enquanto).
<td>
Table data, "dado da tabela": uma célula. Três por linha: item, descrição e preço.
<style>…</style>
Duas linhas de CSS, só para desenhar as bordas. Sem elas, a tabela não tem linha nenhuma, e fica difícil ver as células. border-collapse: collapse junta as bordas vizinhas numa linha só. O assunto do projeto é o HTML; o CSS é explicado em Ligar CSS (quer aprender mais? futuro Guia CSS).
Um tbody que você não escreveu

Abra as Ferramentas do Desenvolvedor (F12) e olhe a tabela na aba dos elementos: entre o table e as linhas aparece um tbody. O navegador sempre coloca as linhas soltas dentro de um tbody, o "corpo da tabela". Na versão 2, você vai escrevê-lo você mesmo.

O que o navegador faz: cria uma quarta coluna para a tabela inteira. A célula "Novidade!" fica sobrando para fora, e as outras linhas ficam com um buraco no fim (sem borda, porque ali não existe célula). O que o validador diz:

$ vnu --verbose index.html
index.html
"file:/home/ana/sites/cardapio/index.html":25.25-26.9: info warning: A table row was 4 columns wide and exceeded the column count established by the first row (3).

"Uma linha da tabela tinha 4 colunas e passou do número de colunas definido pela primeira linha (3)." Repare que é um info warning, um conselho, e não um erro: o código de saída continua 0. Mas a tabela ficou torta. Como consertar: toda linha com o mesmo número de células. A novidade pode ir dentro da descrição: <td>Porção com 6 unidades. Novidade!</td>.

Versão 2 · O cabeçalho e a legenda

Na versão 1, "Item", "Descrição" e "Preço" são células comuns: para o navegador, "Item" é um prato igual ao pão de queijo. Agora eles viram cabeçalhos. E a tabela ganha uma legenda, o nome dela, como a placa em cima do cardápio de uma lanchonete.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Cardápio — Café da Ana</title>
  <style>
    table { border-collapse: collapse; }
    th, td { border: 1px solid #999; padding: 6px 10px; text-align: left; }
  </style>
</head>
<body>
  <h1>Café da Ana</h1>
  <p>Tudo feito na hora, com receitas da família.</p>
  <table>
    <caption>Cardápio de outubro de 2026</caption>
    <thead>
      <tr>
        <th scope="col">Item</th>
        <th scope="col">Descrição</th>
        <th scope="col">Preço</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Pão de queijo</td>
        <td>Porção com 6 unidades</td>
        <td>R$ 9,00</td>
      </tr>
      <tr>
        <td>Bolo de cenoura</td>
        <td>Fatia com cobertura de chocolate</td>
        <td>R$ 8,00</td>
      </tr>
      <tr>
        <td>Café coado</td>
        <td>Xícara de 150 ml</td>
        <td>R$ 5,00</td>
      </tr>
      <tr>
        <td>Brigadeiro</td>
        <td>Unidade</td>
        <td>R$ 3,50</td>
      </tr>
    </tbody>
  </table>
</body>
</html>
<caption>
A legenda: o nome da tabela. Tem de ser o primeiro filho do table. O navegador mostra centralizada, em cima. O leitor de tela costuma anunciar o nome da tabela antes de ler as células, e a pessoa já sabe do que se trata.
<thead>
Table head, "cabeça da tabela": a linha dos títulos das colunas.
<th scope="col">
Table header, "célula de cabeçalho". O navegador mostra em negrito (e centralizada, se o CSS não disser outra coisa; aqui o text-align: left deixou à esquerda). scope="col" diz que ela é o título da coluna de baixo.
<tbody>
Table body, "corpo da tabela": os itens.

Para que tudo isso, se a tela quase não mudou? Quem ouve a página num leitor de tela não vê as colunas. Com th e scope, ao chegar em "R$ 8,00", o leitor pode dizer "Preço, R$ 8,00": ele sabe qual cabeçalho pertence a cada célula. Sem eles, a pessoa ouve uma fila de palavras soltas.

Versão 3 · Os grupos: salgados, doces e bebidas

O cardápio cresceu: agora tem coxinha e suco. Num cardápio de papel, os itens ficam em grupos, cada um com um título. Na tabela, cada grupo vira um tbody próprio (uma tabela pode ter vários), e o título do grupo é uma linha com uma célula que ocupa as três colunas. De quebra, o nome de cada item vira o cabeçalho da sua linha.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Cardápio — Café da Ana</title>
  <style>
    table { border-collapse: collapse; }
    th, td { border: 1px solid #999; padding: 6px 10px; text-align: left; }
  </style>
</head>
<body>

  <p>Tudo feito na hora, com receitas da família.</p>

<tbody> … </tbody> <tbody>
Um corpo para cada grupo. Na tela não muda nada; para o navegador e o leitor de tela, as linhas ficam agrupadas.
colspan="3"
Column span, "ocupa colunas": a célula ocupa o lugar de três. Por isso essa linha tem uma célula só, e mesmo assim fecha a conta das três colunas.
scope="rowgroup"
Este cabeçalho é o título do grupo de linhas (o tbody em que ele está).
<th scope="row">Coxinha</th>
O nome do item é o cabeçalho da linha: ao chegar em "R$ 7,50", o leitor de tela pode dizer "Coxinha, Preço, R$ 7,50".
scopeO cabeçalho vale para…No cardápio
cola coluna de baixoItem, Descrição, Preço
rowa linha da direitaPão de queijo, Coxinha…
rowgroupo grupo de linhas (o tbody)Salgados, Doces, Bebidas
colspan com a conta errada

No título "Doces", a Ana escreveu colspan="2". A tabela tem três colunas, então a linha ficou com uma a menos:

$ vnu --verbose index.html

Tabela é para dados, não para montar a página

Antigamente, sites inteiros eram montados com tabelas: o menu numa coluna, o texto em outra. Não faça isso. O leitor de tela anuncia "tabela, 2 colunas" e a pessoa acha que vai ouvir dados. Para posicionar as partes da página, use os elementos semânticos e CSS. Tabela é para o que seria uma planilha: cardápio, horários, notas, medidas.

Desafios extras

  1. Mais uma coluna. Acrescente a coluna "Vegano?" com "sim" ou "não" em cada item. Lembre de aumentar todos os colspan para 4.
  2. Preço com valor de máquina. Troque cada preço por <data value="9.00">R$ 9,00</data>: as pessoas leem "R$ 9,00", os programas leem 9.00 (veja time e data).
  3. Item esgotado. Risque o preço de um item com <del> e escreva "esgotado" do lado (veja Formatação).
  4. Tamanhos. Para o suco, faça duas linhas (300 ml e 500 ml) com o nome "Suco de laranja" numa célula só, usando rowspan="2" (veja Mesclar Células).

Exercícios

1. Numa tabela, o que cada tr representa?

2. A Ana escreveu um texto direto dentro do table, entre duas linhas. Onde o navegador mostra esse texto?

3. Qual scope vai no nome de cada item (Coxinha, Brigadeiro), que fica no começo da linha?

4. Para que serve o caption?

5. Complete a célula de título de grupo que ocupa as três colunas da tabela:

<th scope="rowgroup" >Doces</th>

6. Complete o nome do elemento do rodapé da tabela:

<> <tr><td colspan="3">Combo do dia</td></tr> </tfoot>

Resumo

  • Uma tabela é escrita linha por linha: tr para cada linha, td para cada célula. Toda linha com o mesmo número de células.
  • th marca cabeçalhos; scope diz se vale para a coluna (col), a linha (row) ou o grupo (rowgroup).
  • caption (o nome), thead, um ou mais tbody e tfoot, nessa ordem.
  • colspan faz uma célula ocupar várias colunas; a soma de cada linha tem de fechar.
  • O navegador conserta tabelas erradas (cria tbody e tr, tira texto solto para cima); o validador aponta cada conserto.
  • Tabela é para dados, nunca para montar o layout da página.
