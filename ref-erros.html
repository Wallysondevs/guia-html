HTML Mensagens do Validador

O navegador quase nunca reclama de um HTML errado: ele conserta sozinho, do jeito dele, e segue em frente. Quem reclama é o validador W3C. Esta página junta as mensagens que você mais vai ver, em inglês, como elas saem, com o que cada uma quer dizer, como consertar e a aula onde o assunto é explicado. Todas foram provocadas de verdade, com o vnu 26.10.12 na máquina da Ana. Para aprender a usar o validador, veja a aula Validar o HTML.

Como usar esta página
  • Copie um pedaço da mensagem que apareceu para você (por exemplo, Stray end tag) e procure aqui com Ctrl+F.
  • Os arquivos de teste estão na pasta ~/ref/erros da Ana, um erro por arquivo. No seu computador, o nome do arquivo e os números de linha e coluna serão outros; o texto da mensagem é o mesmo.
  • O validador on-line, validator.w3.org/nu, usa o mesmo programa: as mensagens são idênticas. O botão "Validar no W3C" do editor do guia manda o código para lá (só depois de você confirmar).
  • As mensagens usam aspas tipográficas “assim”. Ao procurar no Google, copie a mensagem inteira, com as aspas.

Como ler uma mensagem

A página de receita da Ana tem dois problemas. O validador, no terminal:

$ vnu receita.html
"file:/home/ana/ref/demo/receita.html":9.1-9.20: error: An “img” element must have an “alt” attribute, except under certain conditions. For details, consult guidance on providing text alternatives for images.
"file:/home/ana/ref/demo/receita.html":1.16-2.6: info warning: Consider adding a “lang” attribute to the “html” start tag to declare the language of this document.
$ echo $?
1
PedaçoO que quer dizer
"file:/home/ana/ref/demo/receita.html"O arquivo, escrito como endereço (file: = um arquivo do computador).
9.1-9.20Onde está o problema: da linha 9, coluna 1 até a linha 9, coluna 20. Quase sempre é a tag inteira em que o erro aparece. Um intervalo como 1.16-2.6 atravessa duas linhas.
error:O tipo: erro. Veja a próxima tabela.
An “img” element must have an “alt” attribute…A mensagem: "Um elemento img precisa ter um atributo alt, a não ser em certas condições."
echo $? → 1O código de saída do vnu: 1 = encontrou pelo menos um erro; 0 = nenhum erro.

Na aula Validar o HTML você aprende a rodar o vnu e a usar o validador on-line.

ComandoO que faz
vnu arquivo.htmlMostra erros, avisos e notas. Sem nenhuma mensagem = tudo certo.
vnu --verbose arquivo.htmlTambém mostra o nome de cada arquivo conferido, mesmo os que passaram (assim você sabe que ele foi lido).
vnu --errors-only arquivo.htmlSó os erros; esconde avisos e notas.
vnu --Werror arquivo.htmlTrata avisos como erros: o código de saída vira 1 se houver qualquer aviso.
vnu .Confere todos os .html da pasta.
vnu --stdout --format json arquivo.htmlAs mensagens em JSON, para outros programas lerem. Vem com o trecho do código ("extract").

Erros em cascata: conserte o primeiro

Um erro pode gerar várias mensagens. Uma <div> que nunca foi fechada dá duas, e uma delas aponta para a linha do </body>, longe do erro de verdade:

$ vnu naofechou.html
"file:/home/ana/ref/erros/naofechou.html":10.1-10.7: error: End tag for  “body” seen, but there were unclosed elements.
"file:/home/ana/ref/erros/naofechou.html":8.1-8.5: error: Unclosed element “div”.

(O espaço duplo em for “body” sai assim mesmo do vnu.) Regras práticas:

  1. Conserte a primeira mensagem e rode o validador de novo. Muitas das outras somem sozinhas.
  2. Se a mensagem aponta para o </body> ou para o fim do arquivo, o erro de verdade está antes: procure a tag que ficou aberta.
  3. Depois de um error fatal, o validador para. Conserte e rode de novo para ver o resto.

Obsoletos

Elementos antigos dão erro (The “center” element is obsolete. Use CSS instead.); atributos antigos de aparência dão aviso (The “align” attribute on the “p” element is obsolete. Use CSS instead.). As listas completas, com o que usar no lugar, estão em Todos os Elementos → Obsoletos e Atributos → Obsoletos.

O que o validador não pega

Passou no validador, mas está errado

Nestes testes da Ana, o vnu não deu nenhuma mensagem:

  • <iframe src="mapa.html"> sem title: o leitor de tela não sabe o que tem no quadro (aula iframe).
  • <a href="index.html"><img src="logo.png" alt=""></a>: um link cujo único conteúdo é uma imagem com alt vazio. O link fica sem nome nenhum para o leitor de tela; o alt devia dizer para onde ele leva ("Início").
  • Bolo&nbps;de cenoura: um nome de entidade errado, com ;. O navegador mostra o texto como está (Entidades).
  • min="10" max="1" num type="number": o formato está certo, a regra não faz sentido.
  • Um texto alternativo ruim, como alt="imagem": o validador só confere se o alt existe, não se ele descreve a imagem.

O validador confere as regras do HTML. Se a página faz sentido, é acessível e diz o que você queria dizer, só você (e os seus leitores) podem conferir. Veja Acessibilidade e Boas Práticas.

Experimente

Esta é a página da Ana e o que o vnu disse dela:

$ vnu receita.html
"file:/home/ana/ref/missao/receita.html":8.22-8.26: error: End tag “h2” seen, but there were open elements.
"file:/home/ana/ref/missao/receita.html":10.3-10.39: error: An “img” element must have an “alt” attribute, except under certain conditions. For details, consult guidance on providing text alternatives for images.
"file:/home/ana/ref/missao/receita.html":9.3-9.6: error: The heading “h3” (with computed level 3) follows the heading “h1” (with computed level 1), skipping 1 heading level.

Repare que o erro da linha 9 veio por último: o vnu confere a ordem dos títulos só depois de ler a página inteira.

Missão: conserte os três erros que o validador mostrou: feche o h1 com a tag certa, troque o h3 pelo nível que vem depois do h1 e dê à imagem o texto alternativo "Bolo de cenoura com cobertura de chocolate". Repare que, na tela, o primeiro erro não muda nada: o navegador já conserta sozinho. Se quiser, use o botão "Validar no W3C" para conferir.

Resumo

  • Formato: "arquivo":linha.coluna-linha.coluna: tipo: mensagem.
  • error = HTML errado (código de saída 1); info warning = aviso (código 0, a não ser com --Werror); info = nota; error fatal = o validador parou.
  • Palavras-chave: stray (sobrando), unclosed (não fechado), in scope (aberto, ao alcance), not allowed as child (fora do lugar), bad value (valor inválido), obsolete (antigo).
  • Conserte a primeira mensagem e rode de novo: um erro gera vários.
  • O validador não confere se a página faz sentido: alt ruim, iframe sem title e entidades com nome errado passam.
