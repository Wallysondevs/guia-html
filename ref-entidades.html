HTML Entidades

Uma entidade (o nome oficial é "referência de caractere") é um código que começa com & e termina com ; e vira um caractere na tela: &lt; vira <, &copy; vira ©. Elas servem para escrever caracteres que o HTML usaria como código (o < e o &), caracteres invisíveis (o espaço que não quebra) e símbolos que não estão no teclado. Esta página reúne as mais usadas. Para aprender com calma, veja a aula Entidades.

Como ler as tabelas
  • A coluna Na tela é desenhada pelo seu navegador, a partir da própria entidade.
  • As colunas Nome e Número mostram o que você escreve no código. As duas formas dão o mesmo caractere.
  • Com <meta charset="utf-8"> (que o guia usa em toda página), você pode digitar direto o ©, o °, o ç e até um emoji. A entidade só é obrigatória para os caracteres da primeira tabela e para os invisíveis. Veja Acentos, UTF-8 e Emoji.

Anatomia de uma entidade

<p>&copy; 2026 Receitas da Ana</p>
<p>&#169; 2026 Receitas da Ana</p>
<p>&#xA9; 2026 Receitas da Ana</p>

As três linhas dão o mesmo resultado. As três formas:

&copy;
Por nome: &, o nome (em inglês, abreviado: "copyright") e ;. Maiúsculas importam: &Aacute; é Á e &aacute; é á.
&#169;
Por número decimal: &#, o número do caractere no Unicode (a tabela de todos os caracteres do mundo) e ;.
&#xA9;
Por número hexadecimal (base 16): &#x, o número e ;. É como o Unicode costuma aparecer escrito: U+00A9.
;
O ponto e vírgula fecha a entidade. Não esqueça: sem ele, às vezes funciona e às vezes não (veja Quando dá errado).

Estes caracteres têm significado especial no HTML. Para que apareçam como texto, escreva a entidade.

O guia faz isso o tempo todo

Todo código que você lê neste guia está dentro de um <pre>, e cada < dele foi escrito como &lt; no arquivo da página. Se não fosse, o seu navegador desenharia os exemplos em vez de mostrá-los. A aula Código mostra isso.

O HTML junta vários espaços seguidos num só (aula Espaços e Quebras de Linha). Estas entidades dão espaços que o navegador respeita e caracteres que não aparecem, mas mudam a quebra das linhas.

Emoji e qualquer caractere por número

Todo caractere do Unicode tem um número, mesmo os que não têm nome de entidade. Ache o número (U+1F382, por exemplo) e escreva &#x + o número + ;.

<p>Feliz aniversário! &#x1F382;</p>
<p>Feliz aniversário! &#127874;</p>
<p>Feito com &#x2764;&#xFE0F; pela Ana</p>

As duas primeiras linhas são o mesmo bolo (1F382 em hexadecimal = 127874 em decimal). Na terceira, o &#xFE0F; pede a versão colorida do coração. O desenho de cada emoji depende do sistema do leitor.

Quando dá errado

Esqueceu o ponto e vírgula: &copy 2026

O que o navegador faz: mostra © 2026 assim mesmo. Para não quebrar sites antigos, o navegador ainda entende umas cem entidades velhas sem o ; (como &copy, &lt, &amp e &nbsp). As mais novas, como &hellip e &rarr, aparecem como texto, letra por letra.

O validador:

$ vnu ent1.html
"file:/home/ana/ref/ent1.html":8.4-8.9: error: Named character reference was not terminated by a semicolon. (Or “&” should have been escaped as “&amp;”.)

"A referência de caractere com nome não terminou com ponto e vírgula. (Ou o & devia ter sido escrito como &amp;.)" Conserto: &copy; 2026.

Errou o nome: Bolo&nbps;de cenoura

O que o navegador faz: mostra o texto como está, Bolo&nbps;de cenoura, porque não existe entidade nbps (o certo é nbsp: "non-breaking space").

O validador: o vnu 26.10 não deu nenhuma mensagem para essa linha no teste da Ana. Um nome de entidade inventado, com ; no fim, pode passar sem aviso. Às vezes ele avisa: no mesmo teste, P&D; deu “&” did not start a character reference. (“&” probably should have been escaped as “&amp;”.), mas &nbps; e &cia; passaram calados. Por isso, confira as entidades com os olhos, no resultado.

Um < solto no texto: se x<y e y>z

O que o navegador faz: lê <y e y> como a tag de abertura de um elemento y (com os atributos e e y), que não existe. Na tela aparece só se xz: o pedaço do meio some.

O validador:

$ vnu ent1.html
"file:/home/ana/ref/ent1.html":12.8-12.14: error: Element “y” not allowed as child of element “p” in this context. (Suppressing further errors from this subtree.)
"file:/home/ana/ref/ent1.html":12.8-12.14: error: The “y” element is a completely-unknown element that is not allowed anywhere in any HTML content.
"file:/home/ana/ref/ent1.html":12.16-12.19: error: End tag “p” seen, but there were open elements.
"file:/home/ana/ref/ent1.html":12.8-12.14: error: Unclosed element “y”.

Conserto: se x&lt;y e y&gt;z. (Com espaço, 3 < 5, o navegador acerta, porque o < não vem antes de uma letra. Mas é melhor criar o hábito de escapar sempre.)

Número fora da tabela: &#128;, &#0;

Alguns números não são caracteres válidos. O validador dá um erro para cada:

$ vnu ent1.html
"file:/home/ana/ref/ent1.html":15.4-15.9: error: A numeric character reference expanded to the C1 controls range.
"file:/home/ana/ref/ent1.html":15.13-15.16: error: Character reference expands to zero.
"file:/home/ana/ref/ent1.html":15.20-15.27: error: Character reference expands to a surrogate.
"file:/home/ana/ref/ent1.html":15.31-15.40: error: Character reference outside the permissible Unicode range.

Os testes foram &#128;, &#0;, &#xD800; e &#x110000;. O caso curioso é o primeiro: &#128; era o € numa tabela antiga do Windows, e os navegadores, por compatibilidade, ainda mostram €. O número certo do euro é &#8364;.

O & num endereço: href="busca.html?q=bolo&tipo=doce"

Este passou sem erro no validador e funciona no navegador, porque &tipo não é o começo de nenhuma entidade. Mesmo assim, o jeito mais seguro é escrever &amp; também dentro do atributo: href="busca.html?q=bolo&amp;tipo=doce". O navegador transforma o &amp; em & antes de seguir o link.

Experimente

Experimente: escreva entidades das tabelas e veja o seu navegador desenhá-las. Tire um ponto e vírgula, erre um nome, troque o nome pelo número.

<p>&copy; 2026 Receitas da Ana &middot; Forno a 180&deg;C &middot; &frac12; xícara de açúcar</p>
<p>Avaliação: &starf;&starf;&starf;&starf;&star; &rarr; 4 de 5</p>
<p>Bolo &amp; Cia: de R$&nbsp;12,90 por R$&nbsp;9,90 &#x1F382;</p>

Missão: a Ana quer mostrar a tag <h1> no texto, mas o navegador entende que é um título de verdade e a página fica estranha. Use entidades para que a tag apareça como texto dentro do <code>.

<p>Para fazer o título principal, use <code><h1></code>.</p>

<p>Para fazer o título principal, use <code>&lt;h1&gt;</code>.</p>

Resumo

  • Entidade: &nome;, &#número; ou &#xhex;. Sempre com ; no fim.
  • Obrigatórias: &lt; para < e &amp; para & no texto; &quot; dentro de atributo com aspas duplas. Para mostrar uma entidade como texto: &amp;copy;.
  • &nbsp; segura duas palavras na mesma linha (R$&nbsp;12,90); não serve para dar espaço.
  • Com <meta charset="utf-8">, acentos, símbolos e emoji podem ser digitados direto.
  • O navegador perdoa o ; esquecido em entidades antigas; o validador não. Um nome inventado com ; passa no validador, então confira o resultado.
