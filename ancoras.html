HTML Âncoras na Mesma Página

A receita de bolo da Ana ficou comprida: história do bolo, ingredientes, modo de preparo, dicas. Quem só quer ver a lista de ingredientes precisa rolar a página até achar. Um link pode levar não só a outra página, mas a um ponto exato de uma página: é a âncora. Nesta aula você vai marcar os pontos da receita com id, criar um sumário clicável no começo e um "voltar ao topo" no fim.

Você vai aprender
  • Como marcar um ponto da página com o atributo id.
  • Como fazer um link para esse ponto: href="#ingredientes".
  • Como montar um sumário e um link "voltar ao topo".
  • Como levar a um ponto de outra página: bolo.html#ingredientes.
  • As regras de um bom id: único, sem espaços, e cuidado com maiúsculas.
  • Os erros reais do validador: id repetido, id com espaço, vazio, e o antigo <a name>.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código: clique nos links e veja o quadro rolar. As mensagens de erro são do validador W3C (vnu, a mesma ferramenta do validator.w3.org), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o marcador de página

Num livro de receitas, você cola marcadores nas páginas que mais usa e escreve neles: "bolo", "pão". Depois, para achar o bolo, puxa o marcador certo.

Na página, o marcador é o atributo id: ele dá um nome a um elemento. O link aponta para esse nome com um # na frente. São duas partes, e as duas são necessárias:

ParteNo livroNa página
O alvoO marcador colado na página<h2 id="ingredientes">
O caminho até ele"Puxe o marcador ingredientes"<a href="#ingredientes">

1. A primeira âncora

<h1>Bolo de fubá</h1>
<p><a href="#ingredientes">Ir para os ingredientes</a></p>

<h2>A história do bolo</h2>
<p style="height: 500px">A avó da Ana fazia este bolo todo domingo… (um texto bem comprido)</p>

<h2 id="ingredientes">Ingredientes</h2>
<ul>
  <li>2 xícaras de fubá</li>
  <li>3 ovos</li>
  <li>1 colher de erva-doce</li>
</ul>
id="ingredientes"
O alvo. O id (de identifier, "identificador") dá um nome único ao título. Ele não aparece na tela. Qualquer elemento pode ter um id (aula class e id).
href="#ingredientes"
O link para o alvo. O # (cerquilha, ou "jogo da velha") quer dizer "nesta página, o elemento cujo id é…". O nome depois do # é igual ao do id, letra por letra, mas o id em si vai sem o #.
style="height: 500px"
Só para o exemplo: deixa o parágrafo alto, como se tivesse muito texto, para a página precisar rolar. Sem rolagem, não há para onde pular.

Clique no link do resultado: o quadro rola até o título "Ingredientes", que fica no alto. Num site de verdade, o endereço na barra do navegador ganha um #ingredientes no fim, e o botão Voltar do navegador leva de volta ao ponto onde você estava.

O pedaço depois do # tem nome

Em https://ana.example/bolo.html#ingredientes, a parte #ingredientes se chama fragmento (em inglês, fragment, ou hash). Ele nunca vai para o servidor: o navegador pede a página bolo.html inteira e, sozinho, rola até o fragmento.

Missão: dê o id="modo-de-preparo" ao título "Modo de preparo" e transforme "Ir para o modo de preparo" num link para ele. Clique no link para testar.

<h1>Bolo de fubá</h1>
<p>Ir para o modo de preparo</p>

<p style="height: 500px">Fubá, ovos, leite, açúcar, óleo, fermento e erva-doce.</p>

<p>Bata tudo no liquidificador e asse por 40 minutos.</p>

2. O sumário e o "voltar ao topo"

O uso mais comum das âncoras é o sumário: uma lista de links no começo de uma página comprida, um para cada parte. E, no fim de cada parte, um link de volta para o começo.

<h1 id="topo">Bolo de fubá</h1>

<nav aria-label="Sumário">
  <ul>
    <li><a href="#ingredientes">Ingredientes</a></li>
    <li><a href="#modo-de-preparo">Modo de preparo</a></li>
    <li><a href="#dicas">Dicas</a></li>
  </ul>
</nav>

<h2 id="ingredientes">Ingredientes</h2>
<p style="height: 300px">Fubá, ovos, leite, açúcar, óleo, fermento e erva-doce.</p>

<h2 id="modo-de-preparo">Modo de preparo</h2>
<p style="height: 300px">Bata tudo no liquidificador e asse por 40 minutos.</p>

<h2 id="dicas">Dicas</h2>
<p>Unte a forma com manteiga e fubá.</p>
<p><a href="#topo">Voltar ao topo</a></p>
<h1 id="topo">
O alvo do "voltar ao topo": o título principal ganhou um id.
<nav aria-label="Sumário">
O <nav> marca um bloco de navegação (aula nav). O aria-label dá um nome a ele, para o leitor de tela anunciar "navegação Sumário" (aula ARIA). O sumário funcionaria sem os dois, mas assim ele fica mais fácil de achar.
<ul> e <li>
Uma lista com marcadores (aula Listas): cada item é um link.
href="#topo"
Volta para o h1.
Dois atalhos para o topo

O HTML tem duas âncoras especiais que funcionam sem nenhum id: href="#top" e href="#" levam sempre ao começo da página (desde que nenhum elemento tenha id="top"). O guia prefere o id="topo" explícito: quem lê o código entende na hora aonde o link vai.

3. Um ponto de outra página

O fragmento pode vir no fim de qualquer endereço. Na página inicial, a Ana quer um link que abra a receita já nos ingredientes:

<p><a href="bolo.html#ingredientes">Ingredientes do bolo de fubá</a></p>
bolo.html
O caminho da página, como em qualquer link (aula Caminhos). Poderia ser receitas/bolo.html ou um endereço completo.
#ingredientes
O fragmento: depois de abrir bolo.html, o navegador rola até o elemento com id="ingredientes" daquela página.

Com endereços completos é igual: https://ana.example/bolo.html#ingredientes. É assim que você manda para alguém um link "direto para a parte que interessa". Se a outra página não tiver aquele id, ela abre normalmente, no começo, sem erro nenhum.

Missão: no index.html, transforme "Como fazer o bolo" num link que abra o bolo.html direto no modo de preparo. Na aba bolo.html, dê o id="modo-de-preparo" ao título certo. Clique e confira: o quadro troca de página e já rola até o modo de preparo.

<h1>Receitas da Ana</h1>
<p>Como fazer o bolo</p>

<h1>Bolo de fubá</h1>
<h2>Ingredientes</h2>
<p style="height: 500px">Fubá, ovos, leite, açúcar, óleo, fermento e erva-doce.</p>
<h2>Modo de preparo</h2>
<p>Bata tudo no liquidificador e asse por 40 minutos.</p>
<p><a href="index.html">Voltar ao início</a></p>

Pular para o conteúdo

Muitos sites começam com um link escondido, que aparece quando a pessoa aperta Tab: "Pular para o conteúdo". Ele é uma âncora para o <main id="conteudo">, e poupa quem navega pelo teclado de passar por todos os links do menu em cada página. O guia mostra como fazer em Teclado e Foco.

Quando dá errado

O link não leva a lugar nenhum (e o validador não avisa)

O que acontece: com href="#preparo" e o alvo id="modo-de-preparo", o clique não faz nada (só o endereço ganha o #preparo). O mesmo com uma letra maiúscula diferente.

O que o validador diz: nada. Ele confere se cada id e cada href estão bem escritos, mas não confere se o #nome de um link existe na página.

Como consertar: copie o id do alvo e cole no href, depois do #. E clique em cada link do sumário antes de publicar.

Duplicate ID: o mesmo id duas vezes 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="utf-8">
<title>Bolo de fubá</title>
</head>
<body>
<h1>Bolo de fubá</h1>
<p><a href="#ingredientes">Ingredientes</a></p>
<h2 id="ingredientes">Ingredientes</h2>
<h2 id="ingredientes">Ingredientes da cobertura</h2>
</body>
</html>

$ vnu duplo.html
"file:/home/ana/site/duplo.html":11.1-11.22: error: Duplicate ID “ingredientes”.
"file:/home/ana/site/duplo.html":10.1-10.22: info warning: The first occurrence of ID “ingredientes” was here.

O que significa: "id duplicado". A segunda linha é uma informação extra (info warning), apontando a primeira vez que o nome apareceu. O navegador leva o link para o primeiro elemento com aquele id; o segundo nunca é alcançado. O CSS e o JavaScript também se confundem com nomes repetidos.

Como consertar: nomes diferentes: ingredientes e ingredientes-cobertura.

Espaço no id: An ID must not contain whitespace

A Ana escreveu o nome do título como ele aparece na tela, com espaços, nas linhas 9 e 10:

$ grep 'preparo' espaco.html
<p><a href="#modo de preparo">Modo de preparo</a></p>
<h2 id="modo de preparo">Modo de preparo</h2>
$ vnu espaco.html
"file:/home/ana/site/espaco.html":9.4-9.30: error: Bad value “#modo de preparo” for attribute “href” on element “a”: Illegal character in fragment. Space is not allowed.
"file:/home/ana/site/espaco.html":10.1-10.25: error: Bad value “modo de preparo” for attribute “id” on element “h2”: An ID must not contain whitespace.

O que significa: dois erros, um de cada lado: "caractere ilegal no fragmento: espaço não é permitido" (no href) e "um ID não pode conter espaços" (no id).

Como consertar: modo-de-preparo, com hífens, nos dois lugares.

id vazio: An ID must not be the empty string

Com <h2 id=""> na linha 10:

$ vnu vazio.html
"file:/home/ana/site/vazio.html":10.1-10.10: error: Bad value “” for attribute “id” on element “h2”: An ID must not be the empty string.

Como consertar: dê um nome, ou apague o atributo.

O jeito antigo: <a name="…">

Tutoriais antigos marcam o alvo com um link sem endereço: <h2><a name="ingredientes">Ingredientes</a></h2>. Os navegadores ainda entendem, mas, na linha 10:

$ vnu nome.html
"file:/home/ana/site/nome.html":10.5-10.27: error: Element “a” is missing required attribute “href”.
"file:/home/ana/site/nome.html":10.5-10.27: info: The “name” attribute is never allowed on the “a” element.
"file:/home/ana/site/nome.html":10.5-10.27: info warning: The “name” attribute on the “a” element is obsolete. Consider putting an “id” attribute on the nearest container instead.

O que significa: o atributo name no a é obsoleto ("considere colocar um atributo id no elemento mais próximo que o contém"). As três linhas apontam o mesmo <a>: um link sem href, com um atributo que o HTML atual não aceita mais nele (never allowed, "nunca permitido"). A saída mistura os três níveis de mensagem: error, info e info warning.

Como consertar: exatamente o que ele sugere: <h2 id="ingredientes">Ingredientes</h2>, sem o <a>.

Resumo

  • Uma âncora tem duas partes: o alvo, marcado com id="nome", e o link, href="#nome". O # só vai no link.
  • Sumário: uma lista de âncoras no começo (de preferência num <nav>). Voltar ao topo: href="#topo" com <h1 id="topo">; #top e # também levam ao começo.
  • Para um ponto de outra página: bolo.html#ingredientes. O fragmento (o pedaço depois do #) nunca vai ao servidor.
  • O id é único, sem espaços, não vazio, e as maiúsculas contam. Prefira minúsculas com hífen: modo-de-preparo.
  • Validador: Duplicate ID, An ID must not contain whitespace, must not be the empty string e o name obsoleto no a. Um #nome que não existe ou com maiúscula trocada passa calado: clique para testar.
