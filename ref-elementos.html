HTML Todos os Elementos

Esta é a lista de consulta de todos os elementos do HTML de hoje (o HTML Living Standard), separados por assunto. Cada linha diz, em uma frase, para que o elemento serve, se ele tem tag de fechamento e em que aula do guia ele é explicado com calma. No fim estão os elementos obsoletos, que você ainda vai encontrar em sites antigos, com a mensagem real do validador W3C.

Como usar esta página
  • Procure um elemento com Ctrl+F: digite o nome dele com o sinal de menor, por exemplo <abbr.
  • A coluna Fechamento diz como o elemento termina:
    • obrigatório: sempre escreva a tag de fechamento (</strong>);
    • vazio: o elemento não tem conteúdo nem tag de fechamento (<br>, <img>);
    • pode faltar: as regras do HTML deixam omitir o fechamento em certas situações. Mesmo assim, o guia sempre fecha, porque o código fica mais fácil de ler e de consertar.
  • A última coluna leva à aula. Para os atributos de cada elemento, veja a referência de Atributos.

Anatomia de um elemento

Um elemento é uma peça da página: um título, um parágrafo, uma imagem. Ele é escrito com tags (etiquetas) entre os sinais < e >:

<p class="aviso">Bolo de <strong>cenoura</strong>.</p>
<img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate">
<p class="aviso">
A tag de abertura: o nome do elemento (p, de "paragraph", parágrafo) e, se precisar, os atributos (class="aviso").
Bolo de … .
O conteúdo: texto e outros elementos. Aqui há um <strong> dentro do <p> (veja Aninhamento).
</p>
A tag de fechamento: a barra / e o mesmo nome.
<img …>
Um elemento vazio: só a tag de abertura, sem conteúdo e sem </img>.

Se o arquivo da imagem não existisse, o navegador mostraria no lugar dela o texto do alt (ou um ícone de imagem quebrada). Saiba mais em Elementos e Tags.

Os elementos vazios

São só 13, e vale decorar: area, base, br, col, embed, hr, img, input, link, meta, source, track e wbr. Eles não têm conteúdo, então não têm tag de fechamento.

  • <br> e <br /> são a mesma coisa no HTML. A barra no fim é permitida, mas não faz nada; o guia não usa. O validador só deixa uma nota (info, que não é erro): Trailing slash on void elements has no effect and interacts badly with unquoted attribute values.
  • Escrever </img> é um erro: Stray end tag “img”. ("tag de fechamento perdida"). O </br> também (End tag “br”.), e o navegador ainda faz uma coisa estranha com ele: desenha uma quebra de linha, como se fosse um <br>. Veja Mensagens do Validador.
  • Num elemento que não é vazio, a barra não fecha nada: <div /> é só uma tag de abertura de div. O validador avisa: Self-closing syntax (“/>”) used on a non-void HTML element. Ignoring the slash and treating as a start tag.

Quando dá errado: um elemento que não existe

Se você erra o nome (<paragrafo>) ou usa um elemento antigo que saiu do HTML (<blink>), o navegador não dá erro: cria um elemento desconhecido, que se comporta como um <span> sem estilo, e mostra o texto normalmente. Por isso o erro passa despercebido. Experimente na primeira caixa do Experimente: troque um <p> por <paragrafo> e veja que o texto continua lá, só que grudado no resto.

O validador pega na hora, com duas mensagens para o mesmo lugar:

$ vnu erros1.html
"file:/home/ana/ref/erros1.html":8.1-8.11: error: Element “paragrafo” not allowed as child of element “body” in this context. (Suppressing further errors from this subtree.)
"file:/home/ana/ref/erros1.html":8.1-8.11: error: The “paragrafo” element is a completely-unknown element that is not allowed anywhere in any HTML content.

A primeira diz que o elemento não pode ficar ali (e que o validador não vai olhar o que está dentro dele); a segunda, que esse elemento não existe em lugar nenhum do HTML.

Experimente

Experimente: esta é a receita da Ana, com elementos de quase todos os grupos desta página. Mude os elementos, troque um pelo outro (strong por b, ul por ol) e veja o resultado mudar.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Bolo de cenoura</title>
</head>
<body>
  <header>
    <h1>Receitas da Ana</h1>
  </header>
  <main>
    <article>
      <h2>Bolo de cenoura</h2>
      <p>Publicado em <time datetime="2026-10-17">17 de outubro</time>. <mark>Sem glúten!</mark></p>
      <ul>
        <li>3 cenouras</li>
        <li>4 ovos</li>
        <li>2 xícaras de farinha de arroz</li>
      </ul>
      <p><strong>Cuidado:</strong> o forno deve estar a 180 &deg;C.</p>
      <details>
        <summary>Dica da Ana</summary>
        <p>Bata as cenouras com os ovos no liquidificador.</p>
      </details>
    </article>
  </main>
  <footer>
    <p><small>Receitas da Ana, 2026</small></p>
  </footer>
</body>
</html>

Missão: use os elementos de texto certos. Marque as teclas Ctrl e S, cada uma com o seu elemento de tecla, e marque a sigla HTML com o elemento de abreviação, com a forma por extenso HyperText Markup Language. Dica: procure na tabela Texto.

Resumo

  • Um elemento = tag de abertura + conteúdo + tag de fechamento. Os 13 vazios (br, img, input, meta, link, hr…) só têm a abertura.
  • No head: title, meta, link, style, base, script. Eles não aparecem na tela.
  • Semântica: header, nav, main, article, section, aside, footer. Sem significado: div (bloco) e span (em linha).
  • Texto: strong (importância) × b (destaque visual), em (ênfase) × i (voz diferente), del (removido) × s (não vale mais).
  • Obsoletos (center, font, marquee…) ainda aparecem na tela, mas o validador dá erro. Troque por CSS ou pelo elemento indicado.
  • Um nome errado não dá erro no navegador; só o validador pega.
