HTML checkbox e radio

Na ficha de encomenda da Ana há dois tipos de pergunta. "Quer vela e cartão?" aceita nenhuma, uma ou as duas respostas. "Qual o tamanho do bolo?" aceita uma só: ninguém encomenda um bolo pequeno e grande ao mesmo tempo. Para o primeiro tipo, o HTML tem a caixa de marcar (checkbox); para o segundo, o botão de opção (radio). Os dois são um <input> com um type diferente. Nesta aula você vai montar os dois, entender como o navegador forma os grupos e o que é enviado, e conhecer os erros que o validador pega e os que ele deixa passar.

Você vai aprender
  • Como criar uma caixa de marcar (type="checkbox") e um botão de opção (type="radio").
  • Como o name junta os botões de opção num grupo, em que só um fica marcado.
  • O que é enviado: o value de cada item marcado, e o on de quem esquece o value.
  • Como deixar marcado de saída (checked) e como tornar obrigatório (required).
  • Como ligar o texto ao item com <label>, para clicar no texto também.
  • Os erros mais comuns e as mensagens reais do validador W3C.

Você vai precisar de O Elemento input e label. Os exemplos com o resultado embaixo são desenhados pelo seu navegador: marque e desmarque à vontade. O que é enviado foi conferido no Chromium 155, e as validações com o validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a lista de compras e o rádio do carro

Numa lista de compras de papel, cada item tem um quadradinho. Você marca quantos quiser: nenhum, um, todos. Cada quadradinho é independente dos outros. Esse é o checkbox (check = "marcar", box = "caixa").

Os rádios antigos de carro tinham uma fileira de botões, um para cada estação. Apertar um fazia o outro saltar para fora: só uma estação tocava por vez. Daí vem o nome radio button, "botão de rádio". No formulário, ele é a pergunta de resposta única.

1. A caixa de marcar: type="checkbox"

<input type="checkbox" id="vela" name="vela" value="sim">
<label for="vela">Quero vela de aniversário</label>

Clique no quadradinho: ele marca. Clique de novo: desmarca. Agora clique no texto "Quero vela de aniversário": também marca, por causa do <label>.

<input type="checkbox">
Uma caixa de marcar. Como todo <input>, não tem tag de fechamento.
id="vela"
A identificação usada pelo <label for="vela">.
name="vela"
O nome com que a resposta é enviada.
value="sim"
O valor enviado quando a caixa está marcada.
<label for="vela">…</label>
O texto da caixa. Nas caixas e bolinhas, o rótulo costuma vir depois do item (nos campos de texto, vem antes). O clique no texto marca a caixa, e isso importa: o quadradinho é pequeno, difícil de acertar com o dedo no celular.

O que é enviado

Uma caixa marcada é enviada como name=value. Uma caixa desmarcada não é enviada: nem o nome aparece. Para quem recebe, "não marcou" é a falta do par.

A caixaMarcadaDesmarcada
<input type="checkbox" name="vela" value="sim">vela=simnada
<input type="checkbox" name="vela"> (sem value)vela=onnada

Sem value, o navegador envia a palavra on ("ligado"). Testamos no Chromium 155: uma caixa marcada sem value foi enviada como vela=on. Para uma caixa sozinha, isso funciona, mas o value deixa claro o que significa.

Já marcada: checked

O atributo booleano checked ("marcado") deixa a caixa marcada quando a página abre. Como todo atributo booleano, basta escrever a palavra (aula Atributos):

<input type="checkbox" id="novidades" name="novidades" value="sim" checked>
<label for="novidades">Quero receber as novidades da padaria</label>
Não marque por ela

Caixa de "quero receber propaganda" já marcada é uma armadilha: muita gente não lê e envia. No Brasil, a LGPD (a lei de proteção de dados) pede que o consentimento seja uma escolha clara da pessoa. Use checked para preferências óbvias, e não para pedir permissão.

2. Várias caixas com o mesmo nome

Quando as caixas respondem à mesma pergunta ("Adicionais"), elas podem ter o mesmo name, cada uma com seu value:

<p>Adicionais:</p>
<input type="checkbox" id="granulado" name="adicionais" value="granulado">
<label for="granulado">Granulado</label>
<input type="checkbox" id="morango" name="adicionais" value="morango">
<label for="morango">Morangos</label>
<input type="checkbox" id="cartao" name="adicionais" value="cartao">
<label for="cartao">Cartão</label>

Experimente: marque Granulado e Cartão e clique em Enviar. O editor do guia não tem servidor: ele mostra uma página "Formulário enviado" com o que seria enviado. Veja as duas linhas com o mesmo nome, adicionais. Volte, desmarque tudo e envie de novo: a tabela não tem nenhum adicionais.

<form action="enviar.php">
  <p>Adicionais:</p>
  <input type="checkbox" id="granulado" name="adicionais" value="granulado">
  <label for="granulado">Granulado</label>
  <input type="checkbox" id="morango" name="adicionais" value="morango">
  <label for="morango">Morangos</label>
  <input type="checkbox" id="cartao" name="adicionais" value="cartao">
  <label for="cartao">Cartão</label>
  <p><button type="submit">Enviar</button></p>
</form>

Repare: o name se repete, mas cada id é diferente. O id nunca pode repetir na página (veja em Quando dá errado). Cada caixa marcada vira um par, todos com o mesmo nome. Testamos no Chromium 155 com Granulado e Morangos marcados: adicionais=granulado&adicionais=morango. Mesmo com o mesmo nome, as caixas continuam independentes: marcar uma não desmarca a outra.

3. O botão de opção: type="radio"

Agora a pergunta de resposta única. Os botões de opção de uma mesma pergunta formam um grupo, e quem forma o grupo é o name: todos os radio com o mesmo name no mesmo formulário são um grupo só.

<p>Tamanho do bolo:</p>
<input type="radio" id="tam-p" name="tamanho" value="p">
<label for="tam-p">Pequeno</label>
<input type="radio" id="tam-m" name="tamanho" value="m" checked>
<label for="tam-m">Médio</label>
<input type="radio" id="tam-g" name="tamanho" value="g">
<label for="tam-g">Grande</label>

Marque Pequeno: Médio desmarca sozinho. Tente desmarcar Pequeno clicando nele de novo: não dá. Num grupo de rádio, a única forma de tirar a marca é marcar outro. Com o teclado, chegue no grupo com Tab e use as setas para trocar: o Tab pula o grupo inteiro de uma vez.

name="tamanho"
O mesmo nos três: é isso que faz deles um grupo. É também o nome do envio.
value="p"
O valor enviado se este for o escolhido: tamanho=p. No rádio, o value é indispensável: sem ele, os três enviariam o mesmo tamanho=on, e ninguém saberia qual foi.
checked
O marcado de saída. No máximo um por grupo.
id="tam-p"
Cada um tem o seu, para o seu <label>.

E se nenhum tiver checked? O grupo começa sem nada marcado e, se a pessoa não escolher, nada é enviado. Depois que ela marca um, não consegue mais voltar ao "nada".

O texto "Tamanho do bolo:" num <p>?

Funciona para a vista, mas o leitor de tela não liga esse parágrafo ao grupo: ele anuncia "Pequeno, botão de opção" sem dizer que é o tamanho. O jeito certo de dar um título a um grupo é o <fieldset> com <legend>, a próxima aula: fieldset e legend.

Missão: estes dois botões deveriam ser um grupo, mas cada um tem um name diferente. Marque os dois no resultado e veja o problema. Depois conserte: os dois com name="entrega", e com os valores retirar e casa. Teste de novo: agora só um fica marcado.

<p>Como você quer receber?</p>
<input type="radio" id="retirar" name="retirar">
<label for="retirar">Retirar na padaria</label>
<input type="radio" id="casa" name="casa">
<label for="casa">Entregar em casa</label>

<p>Como você quer receber?</p>
<input type="radio" id="retirar" name="entrega" value="retirar">
<label for="retirar">Retirar na padaria</label>
<input type="radio" id="casa" name="entrega" value="casa">
<label for="casa">Entregar em casa</label>

4. O rótulo por fora ou por dentro

Até aqui, o <label> veio ao lado, ligado pelo for e pelo id. Existe outra forma: pôr o item dentro do rótulo. Aí não precisa de for nem de id:

<label><input type="radio" name="cobertura" value="chocolate"> Chocolate</label>
<label><input type="radio" name="cobertura" value="brigadeiro"> Brigadeiro</label>
<label><input type="radio" name="cobertura" value="nenhuma"> Sem cobertura</label>
FormaEscritaQuando
Por fora<input id="x" …> <label for="x">Texto</label>Quando o texto fica longe do item (numa tabela, numa coluna separada).
Por dentro<label><input …> Texto</label>Quando o texto fica colado no item. Menos atributos para errar.

As duas funcionam igual: o clique no texto marca o item, e o leitor de tela lê o texto. O que não pode é pôr dois itens dentro do mesmo rótulo (você vai ver o erro adiante).

5. Obrigatório: required

O required ("obrigatório") funciona diferente em cada tipo:

  • Numa caixa de marcar, ele exige que aquela caixa esteja marcada. Serve para "Li e aceito as regras da encomenda".
  • Num grupo de rádio, basta escrever required em um dos botões, e o grupo inteiro passa a exigir uma escolha. No Chromium 155, com required só no primeiro botão, o grupo ficou inválido com nada marcado e válido assim que marcamos o segundo. Para quem lê o código, o costume é escrever required no primeiro.
<form>
  <p>Pagamento:</p>
  <label><input type="radio" name="pagamento" value="pix" required> Pix</label>
  <label><input type="radio" name="pagamento" value="dinheiro"> Dinheiro</label>
  <p><label><input type="checkbox" name="regras" value="aceito" required> Li e aceito as regras da encomenda</label></p>
  <button type="submit">Enviar pedido</button>
</form>

Clique em Enviar pedido sem marcar nada: o navegador não envia e mostra um balão no primeiro item que falta. O texto do balão é do navegador e muda de um para outro. A aula Validação conta tudo sobre essas mensagens.

Uma dica de desenho: uma caixa sozinha deve fazer sentido marcada e desmarcada. "Quero vela" funciona; "Sim" e "Não" como duas caixas, não (a pessoa pode marcar as duas). Para "sim ou não" com duas opções, use dois rádios.

Quando dá errado

Os arquivos desta seção são páginas completas com o mesmo começo de 7 linhas (<!DOCTYPE html> até <body>, como em Estrutura de uma Página). O código mostrado começa na linha 8. Atenção: vários erros desta aula não aparecem no validador, porque o HTML está correto e o problema é de sentido.

Rádios com nomes diferentes: dá para marcar todos

Como na primeira missão: cada botão com um name é um grupo de um botão só. A pessoa marca dois, três, e não consegue desmarcar nenhum. O validador não reclama: para ele, são vários grupos de uma opção.

Como consertar: o mesmo name em todos os botões da mesma pergunta.

Rádio sem value: chega on

Com <input type="radio" name="tamanho"> nos três botões, o envio é sempre tamanho=on, qualquer que seja o escolhido. O validador não reclama: value não é obrigatório.

Como consertar: cada rádio com o seu value: value="p", value="m", value="g".

Dois checked no mesmo grupo

Com checked em Pequeno e em Grande, o validador fica quieto, e o navegador marca o último: no Chromium 155, só Grande ficou marcado, e o envio foi tamanho=g. Quem lê o código acha que é Pequeno.

Como consertar: checked em um só.

checked="false" continua marcado 
<input type="checkbox" name="vela" checked="false">

$ vnu falso.html
"file:/home/ana/site/falso.html":8.1-8.51: error: Bad value “false” for attribute “checked” on element “input”.

O que significa: "valor ruim, false, para o atributo checked". Um atributo booleano vale pela presença, e não pelo valor. Os únicos valores aceitos são nenhum (checked), vazio (checked="") ou o próprio nome (checked="checked").

O que o navegador faz: vê que o atributo existe e marca a caixa. No Chromium 155, essa caixa veio marcada e foi enviada como vela=on. O "false" foi ignorado.

Como consertar: para desmarcada, apague o atributo.

Dois itens dentro do mesmo rótulo 
<label>Tamanho <input type="radio" name="tam" value="p"> P <input type="radio" name="tam" value="g"> G</label>

$ vnu rotulo.html
"file:/home/ana/site/rotulo.html":8.60-8.100: error: The “label” element may contain at most one “button”, “input”, “meter”, “output”, “progress”, “select”, or “textarea” descendant.
"file:/home/ana/site/rotulo.html":8.1-8.7: info warning: “label” element with multiple labelable descendants.

O que significa: o erro diz "o elemento label pode ter no máximo um button, input, … dentro dele" e aponta o segundo rádio (coluna 60). A linha info warning é um aviso informativo, que não conta como erro: "label com vários elementos rotuláveis dentro", apontando o começo do rótulo.

O que o navegador faz: liga o rótulo só ao primeiro item. Clicar em "G" marca o P.

Como consertar: um <label> para cada item: <label><input type="radio" name="tam" value="p"> P</label> e outro para o G. O título "Tamanho" vai num <legend> (aula fieldset e legend).

O id copiado e colado 
<input type="checkbox" id="vela" name="vela"><label for="vela">Vela</label>
<input type="checkbox" id="vela" name="cartao"><label for="vela">Cartão</label>

$ vnu copiado.html
"file:/home/ana/site/copiado.html":9.1-9.47: error: Duplicate ID “vela”.
"file:/home/ana/site/copiado.html":8.1-8.45: info warning: The first occurrence of ID “vela” was here.

O que significa: "id repetido: vela", e o aviso informativo mostra onde ele apareceu pela primeira vez (linha 8). É o erro clássico de quem copia uma linha e troca só o name.

O que o navegador faz: o for="vela" sempre encontra o primeiro id="vela". Clicar em "Cartão" marca e desmarca a caixa da vela.

Como consertar: id="cartao" e for="cartao" na segunda linha. Ao copiar, troque id, name (se for outra pergunta), value e for.

Resumo

  • type="checkbox": caixa de marcar, independente das outras. type="radio": botão de opção, um só marcado por grupo.
  • O grupo de rádio é formado pelo mesmo name. Nomes diferentes = grupos diferentes = dá para marcar todos.
  • Marcado, o item envia name=value; desmarcado, não envia nada. Sem value, vai on: no rádio, o value é indispensável.
  • checked marca de saída (no rádio, um por grupo); é booleano, e checked="false" continua marcado.
  • required na caixa obriga a marcá-la; em um rádio, obriga o grupo a ter uma escolha.
  • Todo item tem o seu <label>, por fora (for/id, sem repetir id) ou por dentro (um item por rótulo).
