HTML Listas Numeradas

Na aula Listas com Marcadores, a Ana listou os ingredientes do bolo, e a ordem não importava. Agora ela vai escrever o modo de preparo, e aí a ordem é tudo: ninguém põe o bolo no forno antes de bater a massa. Para listas em que a ordem importa, o HTML tem o <ol>, que numera os itens sozinho. Nesta aula você também vai começar de outro número, contar de trás para frente e trocar os números por letras.

Você vai aprender
  • Como montar uma lista numerada com ol e li.
  • Como começar de outro número com start.
  • Como contar de trás para frente com reversed, e por que reversed="false" não desliga nada.
  • Como trocar os números por letras ou algarismos romanos com type.
  • Como mudar o número de um item só com value.
  • Quando usar ol e quando usar ul.
  • Os erros reais do validador para valores errados nesses atributos.

Os quadros Resultado são desenhados pelo seu navegador. As mensagens do validador saíram do vnu 26.10.12 na máquina fictícia da Ana, na pasta ~/site.

A ideia: os passos da receita

Num caderno de receitas, o modo de preparo vem numerado: 1, 2, 3. Se a Ana pular uma linha ou trocar duas de lugar, a receita muda. Os números contam a ordem.

TagVem do inglêsO que é
<ol>ordered list, "lista ordenada"a lista inteira, em que a ordem importa
<li>list item, "item da lista"cada passo (o mesmo li do ul)

A diferença para o ul é uma letra só na tag, mas muda o que a lista significa: "estes itens estão numa sequência".

1. A primeira lista numerada

<h2>Modo de preparo</h2>
<ol>
  <li>Bata as cenouras, os ovos e o óleo no liquidificador.</li>
  <li>Misture o açúcar e a farinha numa tigela.</li>
  <li>Junte tudo e acrescente o fermento.</li>
  <li>Asse por 40 minutos.</li>
</ol>
<ol> … </ol>
A lista numerada. O </ol> é obrigatório.
<li> … </li>
Um passo. As mesmas regras do ul: os filhos diretos do ol só podem ser li, e dentro do li cabe texto, link, parágrafo…
1. 2. 3. 4.
Os números não estão no código. O navegador conta os li e escreve o número na frente de cada um, com um ponto, no lugar onde o ul põe a bolinha.

A vantagem aparece na hora de mudar a receita: se a Ana inserir um passo novo no meio, todos os números de baixo se ajustam sozinhos. Com números digitados à mão, ela teria de renumerar tudo.

A página completa, com o esqueleto de sempre, passa no validador sem nenhuma mensagem:

2. Começar de outro número: start

Às vezes a lista é interrompida no meio: a Ana explica alguma coisa num parágrafo e depois continua os passos. Uma lista nova começaria do 1 de novo. O atributo start ("início") diz de qual número a contagem começa:

<ol>
  <li>Bata as cenouras, os ovos e o óleo.</li>
  <li>Misture o açúcar e a farinha.</li>
  <li>Junte tudo e acrescente o fermento.</li>
</ol>
<p>Enquanto o forno esquenta, unte a forma com manteiga.</p>
<ol start="4">
  <li>Despeje a massa na forma.</li>
  <li>Asse por 40 minutos.</li>
</ol>
start="4"
O primeiro item desta lista recebe o número 4; os seguintes continuam: 5, 6… O valor é sempre um número inteiro escrito com algarismos. Pode ser 0 ou negativo (start="-1" dá -1, 0, 1…).
as duas listas
Para o HTML, continuam sendo duas listas separadas. O start só muda o número que aparece.

Experimente: a segunda lista deveria continuar a primeira, mas recomeçou do 1. Ponha o atributo certo no segundo <ol> para ele começar do 3.

<ol>
  <li>Lave as cenouras.</li>
  <li>Corte em rodelas.</li>
</ol>
<p>Dica: não precisa descascar.</p>
<ol>
  <li>Bata no liquidificador com os ovos.</li>
  <li>Junte o óleo.</li>
</ol>

<ol>
  <li>Lave as cenouras.</li>
  <li>Corte em rodelas.</li>
</ol>
<p>Dica: não precisa descascar.</p>
<ol start="3">
  <li>Bata no liquidificador com os ovos.</li>
  <li>Junte o óleo.</li>
</ol>

3. De trás para frente: reversed

Num ranking do tipo "os 3 bolos mais vendidos", é comum revelar do terceiro para o primeiro. O atributo reversed ("invertido") faz a contagem descer:

<h2>Os mais vendidos da semana</h2>
<ol reversed>
  <li>Bolo de fubá</li>
  <li>Bolo de chocolate</li>
  <li>Bolo de cenoura</li>
</ol>
reversed
Um atributo booleano: ele não tem valor, basta estar escrito. Presente, a lista conta para trás; ausente, conta para frente (aula Atributos).
3. 2. 1.
O navegador conta quantos itens há (3) e começa por esse número. Se a Ana acrescentar um quarto bolo, a lista passa a começar do 4, sozinha.

Repare que reversed não muda a ordem dos itens: o fubá continua em cima. Só os números descem. Para o bolo de cenoura ficar com o número 1, ele precisa estar por último no código.

reversed e start podem ir juntos. Aí a contagem desce a partir do start:

<ol reversed start="10">
  <li>Dez</li>
  <li>Nove</li>
  <li>Oito…</li>
</ol>

4. Letras e algarismos romanos: type

O atributo type ("tipo") troca os números por outro sistema de contagem. São só cinco valores, e maiúscula e minúscula fazem diferença:

typeConta assimNome
11, 2, 3, 4… (o padrão)números (decimal)
aa, b, c, d…letras minúsculas
AA, B, C, D…letras maiúsculas
ii, ii, iii, iv…romanos minúsculos
II, II, III, IV…romanos maiúsculos
<p>Qual é o ingrediente que deixa o bolo laranja?</p>
<ol type="a">
  <li>Beterraba</li>
  <li>Cenoura</li>
  <li>Espinafre</li>
</ol>
<p>Capítulos do livro de receitas:</p>
<ol type="I">
  <li>Bolos</li>
  <li>Tortas</li>
  <li>Pães</li>
  <li>Doces de festa</li>
</ol>
type="a"
Alternativas de prova: a, b, c. Quem lê pode responder "letra b".
type="I"
Capítulos e partes de documentos: I, II, III, IV.
start com letras
O start continua sendo um número, mesmo com letras: <ol type="a" start="3"> começa do "c" (a terceira letra). start="c" é um erro.
No ul o type é obsoleto; no ol, não

Na aula de Listas com Marcadores, o type do ul deu info warning de obsoleto. No ol ele é válido, porque aqui ele faz parte do sentido: num contrato que diz "conforme o item b", trocar as letras por números quebraria o texto. Quando é só enfeite (você prefere letras porque acha bonito), o lugar é o CSS, com a mesma propriedade list-style-type (quer aprender mais? futuro Guia CSS).

5. Mudar o número de um item: value

O li de um ol aceita o atributo value ("valor"), que força o número daquele item. Os seguintes continuam contando a partir dele:

<ol>
  <li>Abertura da loja</li>
  <li value="10">Promoção do dia</li>
  <li>Sorteio</li>
</ol>

O primeiro item é 1, o segundo virou 10, e o terceiro seguiu para 11. O value é raro; quase sempre o start no ol resolve. E ele só vale em itens de ol: num ul, o validador recusa (veja abaixo).

Faça o teste do embaralhar: se você trocar os itens de lugar, o sentido muda?

Quando dá errado

Os arquivos completos têm as mesmas 7 primeiras linhas do receita.html; o código mostrado começa na linha 8. Em todos estes casos o navegador não mostra erro nenhum: ele ignora o valor que não entendeu, ou faz algo que você não esperava.

error: Bad value “dez” for attribute “start” on element “ol” 
<ol start="dez">
  <li>Junte tudo.</li>
  <li>Asse por 40 minutos.</li>
</ol>

$ vnu start-dez.html
"file:/home/ana/site/start-dez.html":8.1-8.16: error: Bad value “dez” for attribute “start” on element “ol”: Expected a minus sign or a digit but saw “d” instead.

O que significa: "valor ruim, dez, para o atributo start no elemento ol: esperava um sinal de menos ou um algarismo, mas vi um d". O validador lê o valor letra por letra e para na primeira que não pode estar num número.

O que o navegador faz: ignora o start inteiro e começa do 1, como se ele não existisse.

Como consertar: escreva o número com algarismos: start="10". O mesmo vale para value no li.

error: Bad value “false” for attribute “reversed” on element “ol”.

A Ana quis "desligar" o reversed escrevendo false ("falso"):

<ol reversed="false">
  <li>Bronze</li>
  <li>Prata</li>
  <li>Ouro</li>
</ol>

$ vnu reversed-false.html
"file:/home/ana/site/reversed-false.html":8.1-8.21: error: Bad value “false” for attribute “reversed” on element “ol”.

O que significa: um atributo booleano só aceita três formas: reversed, reversed="" ou reversed="reversed". Qualquer outro valor é erro.

O que o navegador faz: a lista sai invertida mesmo assim (3, 2, 1). Para o navegador, o que conta é o atributo existir; o valor é ignorado. Escrever false não desliga nada.

Como consertar: para não inverter, apague o atributo. Para inverter, escreva só reversed.

error: Bad value “x” for attribute “type” on element “ol”. 
<ol type="x">
  <li>Concordo com os termos</li>
  <li>Quero receber novidades</li>
</ol>

$ vnu type-x.html
"file:/home/ana/site/type-x.html":8.1-8.13: error: Bad value “x” for attribute “type” on element “ol”.

O que significa: o type só aceita 1, a, A, i e I. A Ana queria caixinhas de marcar, mas isso não é lista: é formulário (aula checkbox e radio).

O que o navegador faz: ignora o valor e numera com 1, 2.

error: Attribute “start” not allowed on element “ul” at this point. 
<ul start="3">
  <li>Junte tudo.</li>
  <li>Asse por 40 minutos.</li>
</ul>

$ vnu ul-start.html
"file:/home/ana/site/ul-start.html":8.1-8.14: error: Attribute “start” not allowed on element “ul” at this point.

O que significa: "o atributo start não é permitido no elemento ul neste ponto". start, reversed e type com letras são do ol; uma lista de bolinhas não tem número para começar. Com <li value="4"> dentro de um ul, a mensagem é a mesma: Attribute “value” not allowed on element “li” at this point.

O que o navegador faz: desenha bolinhas e ignora o atributo.

Como consertar: se os itens têm ordem, troque o ul por ol (abertura e fechamento).

"1. 1. Bata tudo": o número em dobro (sem erro) 
<ol>
  <li>1. Bata tudo no liquidificador.</li>
  <li>2. Asse por 40 minutos.</li>
</ol>

$ vnu numero-duplo.html
$ echo $?
0                           « válido: o validador não lê o seu texto

O que acontece: o código é válido, mas cada item aparece com dois números, o do navegador e o digitado.

Como consertar: apague os números do texto. Num ol, quem numera é o navegador.

Algarismo romano cortado na margem (sem erro)

Com <ol type="I" start="1999">, o primeiro item é MCMXCIX. O recuo que o navegador reserva para o número tem a largura de uns poucos caracteres, e um número comprido passa para fora dele, colado ou até cortado na beirada esquerda. O mesmo acontece com listas de centenas de itens. Não é erro de HTML; o espaço do recuo se ajusta com CSS (padding-left).

Missão final: o pódio dos bolos

Missão: a Ana quer mostrar o pódio do concurso de bolos, revelando do 3º lugar para o 1º. Hoje é uma lista de bolinhas. Troque por uma lista numerada que conta para trás (3, 2, 1). O campeão, o bolo de cenoura, tem de ficar com o número 1, ou seja, por último. Não pode sobrar nenhum ul.

<h2>Pódio do concurso</h2>
<ul>
  <li>Bolo de cenoura</li>
  <li>Bolo de chocolate</li>
  <li>Bolo de fubá</li>
</ul>

<h2>Pódio do concurso</h2>
<ol reversed>
  <li>Bolo de fubá</li>
  <li>Bolo de chocolate</li>
  <li>Bolo de cenoura</li>
</ol>

Duas mudanças foram necessárias: a tag (de ul para ol reversed, na abertura e no fechamento) e a ordem dos itens, porque o reversed só inverte os números, nunca os itens.

Resumo

  • ol (ordered list) é a lista em que a ordem importa. O navegador numera os li sozinho.
  • start="N" começa a contagem do número N (sempre algarismos, mesmo com letras).
  • reversed conta para trás. É booleano: basta existir; reversed="false" é erro e ainda inverte.
  • type: 1, a, A, i, I. É válido no ol quando a marca faz parte do sentido; para enfeite, use CSS.
  • value num li de ol força o número daquele item.
  • Teste do embaralhar: se a ordem muda o sentido, ol; senão, ul. Nunca digite os números no texto.
  • Valores errados dão Bad value no validador, e o navegador simplesmente ignora o atributo (menos o reversed).
