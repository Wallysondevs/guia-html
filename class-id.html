HTML class e id

Uma regra de CSS como p { color: crimson; } pinta todos os parágrafos. Mas a Ana quer pintar só os parágrafos de promoção, e deixar o "bolo do dia" em destaque. Para isso, o HTML deixa você dar nomes aos elementos, com dois atributos: o class, um nome de grupo, que vários elementos podem ter, e o id, um nome único, que só um elemento da página pode ter. Nesta aula você vai usar os dois, ligá-los ao CSS e ver o erro que o validador mostra quando um id se repete.

Você vai aprender
  • O atributo class e o seletor .nome do CSS.
  • Como dar várias classes ao mesmo elemento.
  • O atributo id e o seletor #nome.
  • A diferença entre os dois e qual usar.
  • Para que mais o id serve: links para um trecho da página, formulários, JavaScript.
  • Os erros reais do validador W3C: Duplicate ID, espaço no id, id vazio.

Os arquivos desta aula foram validados com o validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/classe. As cores que o navegador aplicou foram conferidas no Chrome.

A ideia: a turma e o número de matrícula

Numa escola, cada aluno está numa turma ("3º B") e tem um número de matrícula. A turma tem trinta alunos; o número de matrícula é só daquele aluno. Quando a diretora diz "a turma 3º B vai ao pátio", trinta pessoas se levantam. Quando ela chama a matrícula 2026-0153, levanta uma pessoa só.

O número de matrículaid="receita-do-dia"#receita-do-diaUm só por página
Um aluno em duas turmas (o coral e o 3º B)class="promo destaque".promo e .destaqueUm elemento, vários grupos

Os nomes você inventa: o HTML não tem uma lista de classes ou de ids. Escolha nomes que digam o que o elemento é (promo, preco, receita-do-dia), e não como ele fica (vermelho, grande): se um dia a promoção ficar laranja, uma classe vermelho vai mentir.

1. class: um nome de grupo

A Ana marca os parágrafos de promoção com class="promo" e escreve uma regra de CSS para todos eles:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
  <style>
    .promo {
      color: crimson;
      font-weight: bold;
    }
  </style>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <p class="promo">Bolo de cenoura pela metade do preço!</p>
  <p>O bolo de cenoura leva três cenouras médias.</p>
  <p class="promo">Brigadeiro: leve 10, pague 8!</p>
</body>
</html>
class="promo"
No HTML: o atributo class ("classe", no sentido de "categoria", "grupo") com o nome que você escolheu. Dois parágrafos estão no grupo promo; o do meio, não.
.promo
No CSS: o ponto antes do nome quer dizer "todo elemento com a classe promo". O ponto fica só no CSS, nunca no HTML.
{ color: crimson; font-weight: bold; }
Os ajustes, como na aula Ligar CSS.

Os dois parágrafos da classe ficaram vermelho-escuros e em negrito; o do meio, normal. Compare com a aula anterior, O Atributo style: em vez de repetir style="color: crimson; font-weight: bold;" em cada parágrafo, a Ana escreveu o estilo uma vez. Para mudar todas as promoções para laranja, basta mudar uma linha.

A classe não é só para p: qualquer elemento pode ter class, e elementos diferentes podem ter a mesma classe (<h2 class="promo"> também ficaria vermelho). Se você quiser só os parágrafos da classe, o CSS aceita p.promo (sem espaço): "parágrafos com a classe promo".

Várias classes no mesmo elemento

Um elemento pode estar em vários grupos ao mesmo tempo: escreva os nomes no mesmo class, separados por espaço:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
  <style>
    .promo { color: crimson; }
    .destaque { font-size: 1.5em; }
  </style>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <p class="promo destaque">Bolo de cenoura pela metade do preço!</p>
  <p class="promo">Brigadeiro: leve 10, pague 8!</p>
  <p class="destaque">Novidade: torta de limão.</p>
</body>
</html>

O primeiro parágrafo está nos dois grupos: ficou vermelho (de .promo) e maior (de .destaque; 1.5em = uma vez e meia o tamanho normal). O segundo é só promo, e o terceiro, só destaque. A ordem dos nomes no class não importa: class="destaque promo" dá o mesmo resultado.

Espaço, e não vírgula

O espaço separa as classes. Por isso uma classe não pode ter espaço no nome: class="receita do dia" são três classes (receita, do e dia). Para nomes compostos, use hífen: receita-do-dia. E nada de vírgula: class="promo,destaque" é uma classe só, chamada "promo,destaque", que nenhuma regra de CSS acha.

2. id: um nome único

O id (de identifier, "identificador") dá a um elemento um nome que só ele tem na página. No CSS, o id é escrito com # (o "jogo da velha", ou "cerquilha"):

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
  <style>
    #receita-do-dia {
      color: green;
    }
  </style>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <h2 id="receita-do-dia">Receita do dia: bolo de cenoura</h2>
  <h2>Pão de queijo</h2>
  <h2>Brigadeiro</h2>
</body>
</html>
id="receita-do-dia"
No HTML: o nome único. Sem espaços (use hífen) e não pode ser vazio.
#receita-do-dia
No CSS: o # antes do nome quer dizer "o elemento com este id". Como o ponto da classe, o # fica só no CSS.

Se é para pintar um elemento só, por que não um id sempre? Porque o id tem outros empregos, mais importantes que o CSS, e todos dependem de ele ser único:

Para que serve o idExemploAula
Um link que pula para um trecho da página<a href="#receita-do-dia">Ver a receita do dia</a>Âncoras na Mesma Página
Ligar o rótulo ao campo de um formulário<label for="email"> + <input id="email">label
O JavaScript achar um elementodocument.getElementById("receita-do-dia")O Elemento script
Ligar elementos para a acessibilidadearia-describedby="dica-senha"ARIA

Em todos esses casos, o id é um endereço: "vá até aquele elemento". Um endereço que leva a duas casas não serve para nada, como a próxima seção mostra.

3. O id repetido

A Ana queria dois bolos do dia e copiou o id:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Receitas da Ana</title>
  <style>
    .promo { color: crimson; }
    #receita-do-dia { color: green; }
  </style>
</head>
<body>
  <h1>Receitas da Ana</h1>
  <h2 id="receita-do-dia">Bolo de cenoura</h2>
  <p class="promo">Pela metade do preço!</p>
  <h2 id="receita-do-dia">Pão de queijo</h2>
  <p class="promo">Leve 10, pague 8!</p>
</body>
</html>

Olhe o Resultado: os dois títulos ficaram verdes. O CSS não se importa com a repetição, e é por isso que o erro passa despercebido. O validador se importa:

$ vnu id-repetido.html
"file:/home/ana/classe/id-repetido.html":15.3-15.26: error: Duplicate ID “receita-do-dia”.
"file:/home/ana/classe/id-repetido.html":13.3-13.26: info warning: The first occurrence of ID “receita-do-dia” was here.
$ echo $?
1
15.3-15.26: error: Duplicate ID “receita-do-dia”.
"id repetido". A linha 15 é o segundo <h2>: o validador acusa a repetição, e não o primeiro.
13.3-13.26: info warning: The first occurrence of ID “receita-do-dia” was here.
"A primeira vez que esse id apareceu foi aqui", na linha 13. Não é um segundo erro: é uma pista, para você achar as duas linhas.
$? = 1
É um error de verdade: o código de saída do vnu é 1.

E as outras coisas que dependem do id? O Chrome confirmou:

  • o link href="#receita-do-dia" leva sempre ao primeiro, o bolo de cenoura: o pão de queijo nunca é alcançado;
  • document.getElementById("receita-do-dia"), no JavaScript, devolveu só o primeiro (o texto "Bolo de cenoura");
  • num formulário, um <label for="…"> com id repetido fica ligado só ao primeiro campo, e o segundo fica sem rótulo para o leitor de tela.

O conserto depende do que você queria. Se são dois elementos do mesmo grupo, use uma classe. Se cada um precisa do seu endereço, dê ids diferentes (receita-do-dia, receita-de-ontem).

A regra prática: estilo vai em class, endereço vai em id. Mesmo um elemento único (o rodapé, o menu) costuma receber uma classe para o CSS, porque amanhã pode aparecer um segundo, e porque uma regra com # "pesa" mais que uma com . e fica difícil de vencer depois (a "força" dos seletores é assunto do futuro Guia CSS).

Quando dá errado

error: Duplicate ID “receita-do-dia”. + info warning: The first occurrence of ID “receita-do-dia” was here.

O que significa: dois elementos com o mesmo id. O CSS pinta os dois, e por isso parece funcionar; mas o link #receita-do-dia, o label for e o getElementById só enxergam o primeiro.

Como consertar: se são do mesmo grupo, troque por uma class; se cada um precisa de endereço próprio, dê nomes diferentes. Quem costuma causar esse erro é o copiar e colar de um bloco inteiro: depois de colar, procure os id= do pedaço colado.

error: Bad value “receita do dia” for attribute “id” on element “h2”: An ID must not contain whitespace.

O que significa: "valor ruim para o atributo id: um ID não pode ter espaço".

Como consertar: troque os espaços por hífens: receita-do-dia.

error: Bad value “” for attribute “id” on element “h2”: An ID must not be the empty string.

O que significa: um id="", muitas vezes sobra de um modelo que você não preencheu.

Como consertar: dê um nome ou apague o atributo.

error: Duplicate attribute “class”. / Duplicate attribute “id”.

O que significa: o mesmo atributo duas vezes na mesma tag: <p class="promo" class="destaque">. O navegador fica com o primeiro e ignora o segundo, então o parágrafo fica só com promo.

Como consertar: várias classes vão num class só: class="promo destaque". Um elemento tem um id só.

O validador não diz nada, mas a classe "não pega"

O que significa: o nome no HTML e o nome no CSS não são iguais: ponto no HTML (class=".promo"), maiúscula (Promo × .promo), vírgula entre as classes, letra trocada (.promoo), ou o . esquecido no CSS (promo { … } procura um elemento <promo>, que não existe).

Como consertar: copie o nome do HTML e cole no CSS. No F12, o painel de elementos mostra as classes de cada elemento e as regras que ele recebeu: se a sua regra não está na lista, o nome não bateu.

Um link href="#receita-do-di" não pula para lugar nenhum

O que significa: o id do link não existe na página (aqui, faltou uma letra). O validador não confere isso, e o navegador simplesmente não rola a página.

Como consertar: o texto depois do # tem de ser idêntico ao id. Mais em Âncoras na Mesma Página.

Resumo

  • class é um nome de grupo: vários elementos podem ter a mesma classe, e um elemento pode ter várias (class="promo destaque", separadas por espaço). No CSS: .promo.
  • id é um nome único na página. No CSS: #receita-do-dia. Também serve de endereço: href="#…", label for, getElementById.
  • id repetido: error: Duplicate ID “…”. O CSS pinta todos, mas o link e o JavaScript só acham o primeiro. Para um grupo, use classe.
  • Nomes sem espaço (use hífen), não vazios, começando com letra, de preferência em minúsculas. O ponto e o # ficam só no CSS. Maiúsculas contam.
  • Regra prática: estilo vai em class; endereço vai em id.
