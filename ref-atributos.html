HTML Atributos

Os atributos são as informações extras de um elemento: o endereço de um link, o texto alternativo de uma imagem, o idioma da página. Esta página de consulta junta, em tabelas, os atributos que todo elemento aceita (os globais), os atributos de cada elemento, os atributos antigos que não devem mais ser usados e os valores errados mais comuns, com a mensagem real do validador W3C. Para aprender com calma, veja a aula Atributos.

Como usar esta página
  • Procure com Ctrl+F pelo nome do atributo seguido de =, por exemplo href=, ou pelo nome do elemento, por exemplo <img.
  • As mensagens do validador saíram do vnu (o mesmo do validator.w3.org) na máquina da Ana, na pasta ~/ref. No seu computador, o nome do arquivo e o número da linha mudam; o texto da mensagem é o mesmo.
  • Os type do <input> estão na referência Tipos de input, e os <meta>, em Metas do head.

Anatomia de um atributo

Os atributos ficam sempre na tag de abertura, depois do nome do elemento, separados por espaços:

<a href="receitas.html" title="Todas as receitas" class="botao">Ver receitas</a>
href
O nome do atributo. href = "hypertext reference", o endereço do link. O HTML não diferencia maiúsculas de minúsculas nos nomes, mas o costume é escrever tudo em minúsculas.
=
Liga o nome ao valor. Sem espaços em volta é o costume.
"receitas.html"
O valor, entre aspas duplas. Aspas simples ('…') também valem. Sem aspas funciona só se o valor não tiver espaço nem caracteres como ", ', =, <, > e `; o guia sempre usa aspas.
title="…" class="…"
Outros atributos, em qualquer ordem. O mesmo atributo não pode aparecer duas vezes na mesma tag.

Passe o mouse sobre o link do resultado: a dica "Todas as receitas" é o title.

Tipos de valor

Cada atributo espera um tipo de valor. Quando o valor não é do tipo certo, o navegador geralmente ignora o atributo sem avisar, e o validador dá o erro Bad value ("valor ruim"; veja Valores errados).

TipoComo éExemplos
Texto livreQualquer texto.alt="Bolo de cenoura", title="Dica", placeholder="Seu nome"
NúmeroSó algarismos, sem unidade. Largura e altura são em pixels, mas sem o px.width="300", colspan="2", maxlength="40"
BooleanoLiga ou desliga. Estar presente = ligado. Veja abaixo.required, disabled, controls, open
Lista fixa (enumerado)Uma palavra de uma lista definida pelo HTML, quase sempre em inglês.type="email", dir="rtl", loading="lazy", target="_blank"
Endereço (URL)Um caminho relativo ou absoluto. Espaços viram %20.href="sobre.html", src="img/bolo.jpg", href="https://exemplo.com"
IdentificadorUm nome sem espaços, único na página.id="contato", for="nome", list="sabores"
Lista de palavrasVárias palavras separadas por espaço.class="botao grande", rel="noopener noreferrer"
Data e horaNo formato das máquinas: ano-mês-dia, horas com dois-pontos.datetime="2026-10-17", datetime="19:30", min="2026-01-01"

Atributos booleanos: a pegadinha do "false"

Um atributo booleano funciona como um interruptor: estar escrito já liga. As três formas abaixo são iguais e válidas:

<label><input type="checkbox" checked> Com cobertura</label>
<label><input type="checkbox" checked=""> Com granulado</label>
<label><input type="checkbox" checked="checked"> Com morango</label>

Para desligar, apague o atributo. Escrever ="false" não desliga: o navegador vê que o atributo está lá e liga do mesmo jeito. O validador acusa o erro (trechos das saídas):

$ vnu attr.html
"file:/home/ana/ref/attr.html":17.1-17.47: error: Bad value “true” for attribute “checked” on element “input”.
$ vnu attr2.html
"file:/home/ana/ref/attr2.html":10.1-10.45: error: Bad value “false” for attribute “required” on element “input”.

Atributos booleanos comuns: hidden, autofocus, inert, disabled, readonly, required, checked, selected, multiple, novalidate, formnovalidate, controls, autoplay, muted, loop, playsinline, default, reversed, open, async, defer, nomodule, allowfullscreen.

Nem todo "liga e desliga" é booleano

contenteditable, draggable e spellcheck são enumerados: o valor é "true" ou "false" por extenso, e draggable sozinho é um erro (Bad value “” for attribute “draggable” on element “p”.). Já translate usa "yes" ou "no".

Atributos de evento (on…)

Todo elemento aceita atributos que rodam JavaScript quando algo acontece: onclick (clique), oninput (o campo mudou), onsubmit (o formulário vai ser enviado), onload (terminou de carregar)… Eles são válidos, mas misturam o JavaScript com o HTML. O guia prefere o addEventListener num <script>; veja O Elemento script.

Atributos obsoletos

Antes do CSS, a aparência era decidida com atributos: align, bgcolor, border… Os navegadores ainda obedecem à maioria deles, e o vnu 26.10 os aponta como avisos (info warning), não como erros. Mesmo assim, não use: o lugar da aparência é o CSS. Um trecho da saída:

$ vnu attr.html
"file:/home/ana/ref/attr.html":10.1-10.23: info warning: The “bgcolor” attribute on the “body” element is obsolete. Use CSS instead.
"file:/home/ana/ref/attr.html":11.1-11.18: info warning: The “align” attribute on the “p” element is obsolete. Use CSS instead.

bgcolorThe “bgcolor” attribute on the “body” element is obsolete. Use CSS instead.CSS: background-color
width em table e tdThe “width” attribute on the “td” element is obsolete. Use CSS instead.CSS: width. (Em img, video, iframe e canvas, width é válido.)
border em table e imgThe “border” attribute on the “table” element is obsolete. Consider specifying “img { border: 0; }” in CSS instead.CSS: border. A sugestão do validador sobre img sai igual até na tabela: é uma frase pronta dele.

Valores errados e outros erros de atributo

Estes já são erros (error). Todos saíram do vnu com arquivos de teste da Ana. Muitas vezes o navegador não reclama: simplesmente ignora o valor, e você fica sem entender por que nada mudou.

CódigoMensagem real do validadorO que significa e como consertar
<img src="a.png">An “img” element must have an “alt” attribute, except under certain conditions. For details, consult guidance on providing text alternatives for images.Falta o alt. Descreva a imagem, ou use alt="" se ela for só enfeite (Texto Alternativo).
width="200px"Bad value “200px” for attribute “width” on element “img”: Expected a digit but saw “p” instead.O validador esperava um algarismo e achou o p. Tire o px: width="200".
<html lang="pt_BR">Bad value “pt_BR” for attribute “lang” on element “html”: The language subtag “pt_br” is not a valid language subtag.Código de idioma usa hífen, não sublinhado: pt-BR.

Dois id="x"Duplicate ID “x”. e, logo depois, The first occurrence of ID “x” was here.O id precisa ser único na página. A segunda mensagem (um aviso) aponta a linha do primeiro.

Quando dá errado: o "false" que liga

A Ana queria um vídeo que não começasse sozinho e escreveu <video src="receita.mp4" autoplay="false" muted>. O vídeo começa a tocar assim que a página abre. O navegador não olha o valor de um atributo booleano, só se ele existe. O validador avisa: Bad value “false” for attribute “autoplay” on element “video”.

Como consertar: apague o atributo inteiro: <video src="receita.mp4" controls muted>.

Resumo

  • Atributos ficam na tag de abertura: nome="valor", com aspas, sem repetir o mesmo atributo.
  • Globais (em qualquer elemento): id, class, style, title, lang, dir, hidden, tabindex, data-*, aria-*…
  • Booleanos ligam só de estar escritos. ="false" não desliga: apague o atributo.
  • Números sem unidade (width="300"), datas como 2026-10-17, idiomas como pt-BR, valores de lista em inglês (submit, lazy, email).
  • Atributos de aparência (align, bgcolor, border…) são obsoletos: o validador avisa, e o lugar deles é o CSS.
  • Um valor errado quase nunca dá erro no navegador; ele só é ignorado. O validador mostra.
