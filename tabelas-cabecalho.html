HTML Cabeçalhos de Tabela

Na aula Tabelas, a tabela de preços da Ana ficou sem uma coisa importante: a linha do topo que diz o que é cada coluna, "Produto", "Preço", "Estoque". Essas células são cabeçalhos, e o HTML tem uma tag só para elas, o <th>. Nesta aula você também vai dividir a tabela em três partes, cabeçalho, corpo e rodapé, com <thead>, <tbody> e <tfoot>, como a Ana faz no relatório de vendas da semana.

Você vai aprender
  • O que é o th e o que o navegador faz com ele (negrito e centralizado).
  • Cabeçalho de coluna e cabeçalho de linha.
  • Como dividir a tabela em thead, tbody e tfoot, e em que ordem.
  • Por que o navegador cria o tbody sozinho, mas nunca o thead.
  • Por que usar th em vez de td com negrito.
  • Os erros reais do validador: tfoot antes do tbody, thead depois dele, dois thead e th sem tr.

Os quadros Resultado são desenhados pelo seu navegador. Os exemplos com bordas usam o mesmo <head> com duas regras de CSS da aula Tabelas. As mensagens do validador saíram do vnu 26.10.12 na máquina fictícia da Ana, na pasta ~/site.

A ideia: a primeira linha da planilha

Numa planilha de verdade, a primeira linha costuma ser diferente: em vez de dados, ela tem os nomes das colunas, muitas vezes em negrito. Quem lê olha para ela para entender o resto: "este 4 é a quantidade, este R$ 100,00 é o total".

1. A célula de cabeçalho: th

O th é usado no lugar do td, dentro de um tr, nas células que são nomes e não dados:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="utf-8">
<title>Preços</title>
<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid #999; padding: 6px 10px; }
</style>
</head>
<body>
<table>
  <tr>
    <th>Produto</th>
    <th>Preço</th>
    <th>Estoque</th>
  </tr>
  <tr>
    <td>Caderno</td>
    <td>R$ 25,00</td>
    <td>12 unidades</td>
  </tr>
  <tr>
    <td>Caneta azul</td>
    <td>R$ 3,50</td>
    <td>40 unidades</td>
  </tr>
</table>
</body>
</html>
<th>Produto</th>
Uma célula de cabeçalho. Ela fica no mesmo lugar onde ficaria um td: dentro de um tr, e conta como uma célula da linha.
o primeiro <tr>
Uma linha só de th: os nomes das três colunas.
negrito e centralizado
O navegador desenha o th em negrito e com o texto centralizado na célula, enquanto o td fica à esquerda. Esse visual vem pronto; dá para mudar com CSS.

O visual é o de menos. O que importa é o que o th diz: "esta célula é o nome da coluna". Um leitor de tela usa essa informação. Quando a pessoa anda pela tabela e chega no "R$ 3,50", ele pode anunciar "Preço, R$ 3,50", em vez de um número solto. A próxima aula, Legenda e Acessibilidade, mostra como deixar isso ainda mais claro com o atributo scope.

Experimente: na tabela do horário, a primeira linha tem os nomes das colunas, mas foi escrita com td. Troque essas três células por th (na abertura e no fechamento) e veja o negrito e a centralização aparecerem.

2. Cabeçalho de linha

O nome não precisa estar só no topo. Às vezes cada linha também tem um nome, na primeira coluna. Num quadro de vendas por dia, o nome do produto identifica a linha, assim como "Segunda" identifica a coluna:

<table>
  <tr>
    <td></td>
    <th>Segunda</th>
    <th>Terça</th>
  </tr>
  <tr>
    <th>Caderno</th>
    <td>3</td>
    <td>1</td>
  </tr>
  <tr>
    <th>Caneta azul</th>
    <td>5</td>
    <td>8</td>
  </tr>
</table>
<th>Caderno</th>
Um cabeçalho de linha: dá nome aos números à direita dele.
<td></td> no canto
A célula do canto não é nome de nada, então fica como um td vazio. Ela precisa existir para a primeira linha ter 3 células, como as outras.

Agora o "8" tem dois nomes: ele é a venda de Caneta azul (o nome da linha) na Terça (o nome da coluna). Esse exemplo está sem bordas, só para ficar curto; repare que mesmo assim os th se destacam.

3. Cabeça, corpo e pé: thead, tbody e tfoot

Uma tabela pode ser dividida em grupos de linhas. No relatório de vendas, a Ana tem três partes bem diferentes: a linha dos nomes, as linhas de cada produto e a linha do total.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="utf-8">
<title>Vendas</title>
<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid #999; padding: 6px 10px; }
</style>
</head>
<body>
<h1>Vendas da semana</h1>
<table>
  <thead>
    <tr>
      <th>Produto</th>
      <th>Quantidade</th>
      <th>Total</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Caderno</td>
      <td>4</td>
      <td>R$ 100,00</td>
    </tr>
    <tr>
      <td>Caneta azul</td>
      <td>10</td>
      <td>R$ 35,00</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Total da semana</td>
      <td>14</td>
      <td>R$ 135,00</td>
    </tr>
  </tfoot>
</table>
</body>
</html>

$ vnu --verbose vendas.html
vendas.html                 « só o nome: nenhum erro
<thead> … </thead>
A cabeça: a linha (ou as linhas) com os nomes das colunas. No máximo um thead por tabela.
<tbody> … </tbody>
O corpo: as linhas de dados, uma por produto.
<tfoot> … </tfoot>
O pé: a linha de resumo, com os totais. No máximo um.
a ordem
Sempre thead, depois tbody, depois tfoot. Os tr ficam dentro dos grupos.

No resultado, a tabela parece igual a uma sem grupos. Os grupos não mudam o desenho padrão; eles dão significado às partes. E esse significado é usado de várias formas:

  • Leitores de tela distinguem os cabeçalhos dos dados e do resumo.
  • Na impressão, quando uma tabela comprida ocupa várias folhas, os navegadores costumam repetir o thead no topo de cada folha.
  • No CSS, fica fácil pintar só o cabeçalho (thead) ou pôr o total em negrito (tfoot), sem precisar de class em cada linha.

Mais de um tbody

O thead e o tfoot são únicos, mas o corpo pode ter vários tbody, um para cada seção dos dados. A Ana separa a papelaria dos doces:

<table>
  <thead>
    <tr><th>Produto</th><th>Preço</th></tr>
  </thead>
  <tbody>
    <tr><th>Papelaria</th><td></td></tr>
    <tr><td>Caderno</td><td>R$ 25,00</td></tr>
    <tr><td>Caneta azul</td><td>R$ 3,50</td></tr>
  </tbody>
  <tbody>
    <tr><th>Doces</th><td></td></tr>
    <tr><td>Brigadeiro</td><td>R$ 2,00</td></tr>
  </tbody>
</table>

Cada linha foi escrita numa linha só do código, com as células lado a lado. É o mesmo HTML, só mais compacto: use a forma que você ler melhor. (Na aula Mesclar Células, a célula "Papelaria" vai ocupar as duas colunas, sem o td vazio ao lado.)

4. O navegador cria o tbody, mas não o thead

Você viu na aula Tabelas que, se os tr estão direto no table, o navegador cria um tbody em volta deles. E o primeiro exemplo desta aula, com a linha de th no topo? O navegador põe todas as linhas no mesmo tbody, inclusive a dos cabeçalhos:

<table>
  <tbody>
    <tr>
      <th>Produto</th> …   <!-- os th continuam no tbody -->
    </tr>
    <tr>
      <td>Caderno</td> …
    </tr>
  </tbody>
</table>

O navegador não tenta adivinhar qual linha é cabeçalho. Ter th sem thead é válido, e o th continua sendo cabeçalho. Mas um seletor como thead th, no CSS ou nas metas do editor, só encontra os th que você colocou num thead escrito por você.

5. th ou td com negrito?

Um <td><strong>Produto</strong></td> também fica em negrito, e é válido. Por que não usar?

<td><strong>…</strong></td><th>…</th>
O que diz"um dado importante""o nome desta coluna (ou linha)"
Leitor de telalê como mais um dadousa para anunciar o nome da coluna junto de cada dado
Visual padrãonegrito, à esquerdanegrito, centralizado

Qual usar: se a célula é um nome de coluna ou de linha, th. Se é um dado que você quer destacar, td com strong. Repare que esta própria tabela usa th nas duas direções: no topo e na primeira coluna.

Quando dá errado

Nos arquivos completos, as linhas 1 a 11 são o cabeçalho com o <style>; o código mostrado começa na linha 12. Os quadros Resultado mostram só o trecho, sem as bordas.

error: Element “tbody” not allowed as child of element “table” in this context.

A Ana escreveu o rodapé antes do corpo:

<table>
  <tfoot>
    <tr><td>Total</td><td>R$ 135,00</td></tr>
  </tfoot>
  <tbody>
    <tr><td>Caderno</td><td>R$ 100,00</td></tr>
    <tr><td>Caneta azul</td><td>R$ 35,00</td></tr>
  </tbody>
</table>

$ vnu tfoot-antes.html
"file:/home/ana/site/tfoot-antes.html":15.11-16.9: error: Element “tbody” not allowed as child of element “table” in this context. (Suppressing further errors from this subtree.)

O que significa: o erro aponta o tbody (linha 16), e não o tfoot: depois de um tfoot, nenhum outro grupo pode vir. "Neste contexto" quer dizer "depois do que já apareceu".

O que o navegador faz: desenha o total embaixo, no lugar certo, como se estivesse tudo bem. O CSS padrão do navegador sempre desenha o tfoot no fim da tabela, não importa onde ele esteja no código. Mas no DOM ele continua em primeiro, e um leitor de tela pode ler o total antes dos produtos.

Por que isso confunde: no HTML 4 (de 1997), o tfoot tinha de vir antes do tbody, e muitos tutoriais antigos ainda ensinam assim. No HTML atual, ele vem depois.

Como consertar: mova o tfoot inteiro para depois do último </tbody>.

error: Element “thead” not allowed as child of element “table” in this context.

O contrário: o cabeçalho ficou depois do corpo.

<table>
  <tbody>
    <tr><td>Caderno</td><td>R$ 100,00</td></tr>
  </tbody>
  <thead>
    <tr><th>Produto</th><th>Total</th></tr>
  </thead>
</table>

$ vnu thead-depois.html
"file:/home/ana/site/thead-depois.html":15.11-16.9: error: Element “thead” not allowed as child of element “table” in this context. (Suppressing further errors from this subtree.)

O que o navegador faz: de novo, conserta só o desenho: o thead aparece em cima. A ordem no código, que é a ordem lida pelo leitor de tela, continua errada.

Com dois thead na mesma tabela, a mensagem é a mesma, apontando o segundo: o thead é único.

Como consertar: o thead vem antes de tudo (só a legenda, caption, pode vir antes dele).

error: “th” start tag in table body.

A Ana escreveu os th direto no thead, sem o tr:

<table>
  <thead>
    <th>Produto</th>
    <th>Total</th>
  </thead>
  <tbody>
    <tr><td>Caderno</td><td>R$ 100,00</td></tr>
  </tbody>
</table>

$ vnu thead-sem-tr.html
"file:/home/ana/site/thead-sem-tr.html":13.10-14.8: error: “th” start tag in table body.

O que significa: "tag de abertura de th num grupo de linhas". O validador chama de table body qualquer um dos três grupos. Dentro de thead, tbody e tfoot só podem existir tr, e as células ficam dentro deles.

O que o navegador faz: cria o tr que faltou em volta dos dois th, e a tabela aparece certa. É o mesmo conserto do "td sem tr" da aula anterior.

Como consertar: <thead><tr><th>…</th></tr></thead>.

A meta table > * conta os filhos diretos do table no DOM: precisam ser exatamente 3, os três grupos. Curiosidade: se você deixar as linhas de produtos soltas entre o thead e o tfoot, o navegador cria o tbody em volta delas, e a meta também passa (a tag <tbody> pode ser omitida). Mesmo assim, escreva-a: quem ler o código depois vê na hora onde o corpo começa e termina.

Resumo

  • th é a célula de cabeçalho: o nome de uma coluna (no topo) ou de uma linha (na primeira coluna). O navegador a desenha em negrito e centralizada.
  • Use th para nomes e td para dados; td com strong não avisa o leitor de tela que aquilo é um nome.
  • thead (cabeça, um só), tbody (corpo, um ou mais) e tfoot (pé, um só), sempre nessa ordem, com os tr dentro.
  • O navegador cria o tbody quando falta, mas nunca um thead: thead th só encontra o que você escreveu.
  • Fora de ordem, o navegador desenha a cabeça em cima e o pé embaixo, mas o validador acusa Element “tbody”/“thead” not allowed as child of element “table” in this context, e a ordem lida continua errada.
  • Célula direto no grupo, sem tr: “th” start tag in table body.
