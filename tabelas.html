HTML Tabelas

Boletim da escola, tabela de preços, horário do ônibus, tabela do campeonato: quando as informações se cruzam em linhas e colunas, o lugar delas é uma tabela. Nesta aula a Ana monta a tabela de preços da lojinha com três tags, <table>, <tr> e <td>, e descobre duas surpresas: a tabela nasce sem nenhuma linha desenhada, e o navegador acrescenta uma tag que ela não escreveu.

Você vai aprender
  • O que são table, tr e td, e como montar uma tabela.
  • Por que a tabela aparece sem bordas, e as duas regras de CSS que as desenham.
  • Por que a tabela é montada linha por linha, e como acrescentar uma linha ou uma coluna.
  • O que é o tbody que o navegador cria sozinho.
  • O que cabe numa célula, e quando usar (e não usar) uma tabela.
  • Os erros reais do validador: texto solto dentro da tabela, td fora da tabela, td sem tr e o border obsoleto.

Os quadros Resultado são desenhados pelo seu navegador. As mensagens do validador saíram do vnu 26.10.12 na máquina fictícia da Ana, na pasta ~/site.

A ideia: a planilha

Pense numa planilha, ou na grade de um caderno quadriculado. Cada informação mora numa célula, no cruzamento de uma linha (deitada) com uma coluna (em pé). Na tabela de preços da Ana, cada linha é um produto, e cada coluna é um tipo de informação: o nome, o preço, o estoque.

TagVem do inglêsNa planilha
<table>table, "tabela"a planilha inteira
<tr>table row, "linha da tabela"uma linha
<td>table data, "dado da tabela"uma célula

Repare que não existe uma tag para "coluna". Em HTML, a tabela é escrita uma linha de cada vez, e as colunas aparecem sozinhas: a primeira célula de cada linha forma a primeira coluna, a segunda célula forma a segunda coluna, e assim por diante.

1. A primeira tabela

<table>
  <tr>
    <td>Caderno</td>
    <td>R$ 25,00</td>
  </tr>
  <tr>
    <td>Caneta azul</td>
    <td>R$ 3,50</td>
  </tr>
</table>
<table> … </table>
A tabela inteira. Tudo o que é da tabela fica aqui dentro.
<tr> … </tr>
Uma linha. Esta tabela tem duas: a do caderno e a da caneta.
<td>Caderno</td>
Uma célula com o seu conteúdo. Cada linha tem duas: o nome e o preço.
o recuo
Os td recuados dentro do tr, e o tr dentro do table, são só para você ler. O navegador ignora esses espaços.

Olhe o resultado: os dados estão alinhados em duas colunas, mas não há linha nenhuma separando as células. Isso não é defeito: o HTML diz o que é tabela, linha e célula; desenhar as bordas é trabalho do CSS. Sem CSS, o navegador só alinha o conteúdo.

Repare também que o navegador alarga cada coluna o suficiente para o maior conteúdo dela, e não mais que isso. "Caneta azul" é mais comprido que "Caderno", então a primeira coluna tem a largura de "Caneta azul".

2. Desenhar as linhas com CSS

Para enxergar a grade, a Ana põe duas regras de CSS dentro de um <style>, no <head>. Esta é a página completa:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="utf-8">
<title>Preços</title>
<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid #999; padding: 6px 10px; }
</style>
</head>
<body>
<h1>Preços da lojinha</h1>
<table>
  <tr>
    <td>Caderno</td>
    <td>R$ 25,00</td>
    <td>12 unidades</td>
  </tr>
  <tr>
    <td>Caneta azul</td>
    <td>R$ 3,50</td>
    <td>40 unidades</td>
  </tr>
  <tr>
    <td>Estojo</td>
    <td>R$ 18,00</td>
    <td>5 unidades</td>
  </tr>
</table>
</body>
</html>
<style> … </style>
Um bloco de CSS dentro da página (aula Ligar CSS). O assunto aqui é o HTML; o CSS é só o mínimo para ver a grade (quer aprender mais? futuro Guia CSS).
th, td { border: 1px solid #999; }
"Em cada célula, uma borda (border) de 1 pixel, contínua (solid), cinza (#999)." O th é a célula de cabeçalho, da próxima aula.
padding: 6px 10px
"Enchimento": um respiro entre a borda e o texto, de 6 pixels em cima e embaixo e 10 dos lados.
table { border-collapse: collapse; }
"Juntar as bordas": sem isso, cada célula teria a sua própria borda, e entre duas células apareceriam duas linhas paralelas.
$ vnu --verbose precos.html
precos.html                 « só o nome: nenhum erro

Todos os exemplos com bordas das aulas de tabela usam este mesmo <head>, com estas duas regras.

3. Montada linha por linha

Como não existe tag de coluna, cada mudança na tabela segue a regra das linhas:

Para…Faça
acrescentar um produto (uma linha)um <tr> novo, com o mesmo número de td das outras linhas
acrescentar uma informação (uma coluna)um <td> novo em cada tr, sempre na mesma posição
trocar duas colunas de lugartrocar a ordem dos td em todas as linhas

Se uma linha ficar com menos células que as outras, o navegador deixa um buraco no fim dela; se ficar com mais, a célula a mais fica sobrando para fora, numa coluna que só ela tem. O validador avisa nos dois casos. Isso é o assunto de Mesclar Células, onde as células de tamanhos diferentes aparecem de propósito.

4. O tbody que aparece sozinho

Abra as Ferramentas do Desenvolvedor (F12, aula Ferramentas do Desenvolvedor) numa página com a tabela de preços e olhe a árvore de elementos. Entre o table e os tr há um elemento que a Ana não escreveu:

<table>
  <tbody>
    <tr>
      <td>Caderno</td>
      …
    </tr>
    …
  </tbody>
</table>

O tbody (table body, "corpo da tabela") é o grupo das linhas de dados. As regras do HTML dizem que as linhas de uma tabela moram sempre dentro de um grupo; quando você escreve os tr direto no table, o navegador cria o tbody por conta própria, enquanto lê o código. O seu arquivo continua igual; o que muda é a árvore que o navegador monta (o DOM, aula Como o Navegador Lê HTML).

Isso é válido, e o validador não reclama. Mas tem uma consequência prática: um seletor de CSS como table > tr ("tr filho direto de table") não encontra nada, porque no DOM os tr são filhos do tbody. As metas do editor do guia olham o DOM, por isso a próxima missão conta tbody tr, mesmo sem nenhum tbody no código. Na aula Cabeçalhos, você vai escrever o tbody você mesmo, junto com o thead e o tfoot.

5. O que cabe numa célula

Um td aceita quase tudo o que um li aceita: texto, destaques, links, imagens, listas, até outra tabela (o que raramente é boa ideia). Uma célula também pode ficar vazia:

<table>
  <tr>
    <td><strong>Caderno</strong></td>
    <td>R$ 25,00</td>
    <td><em>novo!</em></td>
  </tr>
  <tr>
    <td>Caneta azul</td>
    <td>R$ 3,50</td>
    <td></td>
  </tr>
</table>

A célula vazia continua ocupando o lugar dela, e a linha continua com 3 células. Apagar o <td></td>, em vez de deixá-lo vazio, encurtaria a linha. O conteúdo de uma célula alinha, por padrão, à esquerda e no meio da altura da linha.

6. Quando usar uma tabela

Use tabela quando a informação tem duas direções: cada linha é uma coisa (um produto, um aluno, um dia) e cada coluna é uma característica (preço, nota, horário). A pergunta-teste: faz sentido ler esta informação cruzando uma linha com uma coluna? "Qual é o preço do estojo?" — linha do estojo, coluna do preço.

Não use tabela para posicionar coisas na tela: duas colunas de texto, um menu do lado, uma foto ao lado de um parágrafo. Nos anos 1990 os sites inteiros eram montados assim, porque não havia outro jeito. Hoje o CSS faz o layout, e a tabela de enfeite atrapalha:

  • o leitor de tela anuncia "tabela com 2 colunas e 1 linha" e lê o conteúdo célula por célula, como se fossem dados;
  • no celular, a tabela não se rearruma: ela fica larga demais e a página ganha barra de rolagem para o lado.

Para uma lista simples, use ul; para pares nome → valor, dl (aula Listas de Descrição).

Quando dá errado

Nos arquivos com erro, as linhas 1 a 11 são o mesmo cabeçalho do precos.html (com o <style>); o código mostrado começa na linha 12. Os quadros Resultado mostram só o trecho, sem as bordas.

error: Misplaced non-space characters inside a table.

A Ana quis pôr um título na tabela e escreveu o texto direto dentro do <table>:

<table>
  Preços de outubro
  <tr>
    <td>Caderno</td>
    <td>R$ 25,00</td>
  </tr>
</table>

$ vnu texto-solto.html
"file:/home/ana/site/texto-solto.html":12.8-14.6: error: Misplaced non-space characters inside a table.
"file:/home/ana/site/texto-solto.html":12.8-14.6: error fatal: Cannot recover after last error. Any further errors will be ignored.
Misplaced non-space characters inside a table
"Caracteres que não são espaço, fora do lugar, dentro de uma tabela". Entre as tags da tabela só podem existir espaços e quebras de linha; texto, só dentro das células.
error fatal: Cannot recover after last error
"Erro fatal: não consigo me recuperar depois do último erro. Os próximos erros serão ignorados." O validador para de procurar aqui. Conserte este e rode de novo: pode haver outros mais abaixo.

O que o navegador faz: algo estranho. Ele tira o texto de dentro da tabela e o coloca antes dela. No resultado, "Preços de outubro" aparece acima da tabela, como se você o tivesse escrito antes do <table>. Esse "despejo" para fora tem até nome na especificação do HTML: foster parenting ("adoção"), porque o conteúdo é adotado pelo elemento de fora. O mesmo acontece com um <p> ou um <strong> perdidos entre as linhas.

Como consertar: o título de uma tabela tem lugar próprio, a tag <caption> (aula Legenda e Acessibilidade). Por enquanto, ponha o texto num parágrafo ou título antes do <table>.

error: Stray start tag “td”.

A Ana esqueceu o <table> e o <tr>, e escreveu só as células:

<p>Preços:</p>
<td>Caderno</td>
<td>R$ 25,00</td>

$ vnu sem-table.html
"file:/home/ana/site/sem-table.html":13.1-13.4: error: Stray start tag “td”.
"file:/home/ana/site/sem-table.html":13.12-13.16: error: Stray end tag “td”.
"file:/home/ana/site/sem-table.html":14.1-14.4: error: Stray start tag “td”.
"file:/home/ana/site/sem-table.html":14.13-14.17: error: Stray end tag “td”.

O que significa: stray quer dizer "perdida", "desgarrada": uma tag de abertura (start tag) e uma de fechamento (end tag) de td num lugar onde não pode haver célula.

O que o navegador faz: apaga as tags e deixa só o texto. Não sobra célula nenhuma: "Caderno" e "R$ 25,00" aparecem grudados na mesma linha, como texto comum. É diferente do li solto da aula de Listas, que continuava sendo um li.

Como consertar: toda célula mora num tr, e todo tr mora num table.

error: “td” start tag in table body.

Agora o table existe, mas falta o tr:

<table>
  <td>Caderno</td>
  <td>R$ 25,00</td>
</table>

$ vnu sem-tr.html
"file:/home/ana/site/sem-tr.html":12.8-13.6: error: “td” start tag in table body.

O que significa: "tag de abertura de td no corpo da tabela", ou seja, num lugar onde só pode haver linhas.

O que o navegador faz: conserta sozinho, criando o tbody e um tr em volta das células. A tabela aparece certinha, com uma linha e duas células, e por isso o erro passa despercebido. Mas o validador acusa, e com mais linhas o conserto automático não adivinha onde cada linha termina: todas as células vão para a mesma linha.

Como consertar: escreva o <tr> e o </tr> em volta das células de cada linha.

info warning: The “border” attribute on the “table” element is obsolete.

Em sites antigos e em muitos tutoriais, a borda vem do atributo border:

<table border="1">
  <tr>
    <td>Caderno</td>
    <td>R$ 25,00</td>
  </tr>
</table>

$ vnu border.html
"file:/home/ana/site/border.html":12.1-12.18: info warning: The “border” attribute on the “table” element is obsolete. Consider specifying “img { border: 0; }” in CSS instead.

O que significa: "o atributo border no elemento table é obsoleto". É só um aviso (info warning), e o navegador ainda desenha as bordas, duplas, como você vê no resultado. A segunda frase da mensagem é curiosa: "considere usar img { border: 0; } no CSS". Ela fala de imagens, e não de tabelas: é um texto do validador pensado para outro caso antigo, que aparece aqui também. Não leve a sugestão ao pé da letra.

Como consertar: apague o border="1" e use as duas regras de CSS da seção 2.

Referência rápida

EscritaO que faz
<table>…</table>A tabela inteira.
<tr>…</tr>Uma linha (table row). Só dentro de table (ou de thead, tbody, tfoot).
<td>…</td>Uma célula de dados (table data). Só dentro de tr. Pode ficar vazia.
tbodyCriado pelo navegador quando os tr estão direto no table. Seletores de CSS e metas enxergam o tbody.

<table border="1">Obsoleto (info warning). Use CSS.

Resumo

  • Tabela = table (a tabela), tr (cada linha) e td (cada célula). Não existe tag de coluna: as colunas nascem da posição dos td.
  • Sem CSS, a tabela não tem bordas. border-collapse: collapse e border: 1px solid nas células desenham a grade.
  • Cada linha deve ter o mesmo número de células. Nova coluna = um td em cada tr.
  • O navegador cria um tbody em volta dos tr soltos. O DOM tem tbody mesmo que o código não tenha.
  • Tabela é para dados em linhas e colunas, nunca para montar o layout da página.
  • Erros: Misplaced non-space characters inside a table (o texto é jogado para antes da tabela), Stray start tag “td” (a célula vira texto comum), “td” start tag in table body (faltou o tr) e o border obsoleto.
